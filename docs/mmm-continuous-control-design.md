# MMM 연속형 컨트롤 설계

기준: 2026-08-27 · 대상: `/marketing-response`의 기여 분해

## 결정

기존 `external` 입력과 상대 변화 변환을 폐기하거나 새 회귀 엔진으로 교체하지 않는다. 이 경로를 **연속형 컨트롤**로 명시하고, 입력 계약·적합 상태·해석 한계를 한 흐름으로 연결한다.

컨트롤은 매체 지출이 아닌 주간 수준값이다. 예시는 시장 수요, 가격 지수, 카테고리 검색량이다. 모델은 각 열을 자체 기준 대비 상대 변화로 바꾼 뒤 추세·계절·이벤트·매체와 공동 적합한다.

## 사용자 흐름

1. 매퍼에서 열을 `연속형 컨트롤`로 명시한다. 자동 추정은 기존의 강한 업계·시장 키워드만 유지한다.
2. 화면에서 같은 기간·주기, 결측 없음, 역할 구분을 안내한다.
   - 일회성 0/1 사건: `더미/이벤트`
   - 변경 후 유지되는 0/1 상태: `구조변화 step`
   - 수준이 계속 변하는 비매체 변수: `연속형 컨트롤`
3. `분석하기` 뒤 주 단위 패널을 검증한다. 결측은 임의 보간하지 않고 분석을 중단한다. 상수열과 값이 두 종류뿐인 열은 명시 경고한다.
4. 결과에서 컨트롤별 실제 포함·공선 제외·미사용 상태와 변환 방식을 보여준다.

## 정직성 계약

- 컨트롤을 넣었다고 관측 MMM이 인과 모델로 바뀌지 않는다.
- 컨트롤 계수나 기여를 채널 ROAS, 예산 순위, 증액 후보로 사용하지 않는다.
- 변화가 없거나 다른 변수와 완전히 겹친 컨트롤은 랭크 결손으로 제외하고 그 사실을 표시한다.
- 결측을 0이나 평균으로 대체하지 않는다.
- 내부 feature 접두사 `industry_`와 저장 역할 `external`은 기존 저장본·다운로드 호환을 위해 유지한다. 화면 명칭만 일반 계약에 맞춘다.

## 이번 범위 밖

- 사용자가 고른 컨트롤의 인과적 충분성 판정
- 미래 컨트롤 시나리오 자동 생성
- 범주형 다수준 변수 자동 인코딩
- 외부 데이터 API 수집 또는 서버 저장

## 검증 기준

- 컨트롤이 없는 기존 입력의 수학 결과는 바뀌지 않는다.
- 결측·상수·이진형 컨트롤의 진단이 KO/EN으로 노출된다.
- 적합 결과는 실제 feature 목록과 랭크 제외 목록에서 파생된다.
- 매핑 편집 중에는 원자료 행을 다시 순회하지 않는다. 상세 검증은 분석 게이트 뒤에서만 수행한다.
