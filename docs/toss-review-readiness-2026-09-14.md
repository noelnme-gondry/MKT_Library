# 토스 상점 심사 보완 · 2026-09-14

기준 커밋: `d20c942d` (PR #875). 사용자 제공 토스 상점 심사 화면을 읽고 공개 응답과 코드를 확인했다. 이 문서는 보완 작업 기록이며, 토스에 제출했거나 재심사를 통과했다는 뜻이 아니다.

2026-09-14 후속 지시: 사용자가 제공한 주소 이미지에 따라 `서울특별시 동대문구 천호대로41길 26, 402호(용두동, 천우네오젠)`로 교체했다. 이후 사용자가 토스 계약과정 FAQ를 제공하며 진행을 요청해 심사용 테스트 위젯 경로를 추가한다. **심사 계정 설정과 실결제 활성화는 보류 상태를 유지한다.** 아래 결제·가입 응답은 수정 전 조사 기록이다.

## 접수된 보완 요청과 확인 결과

위 공개 응답은 비로그인 상태에서 확인한 결과다. 실제 Google 로그인, 결제 인증·승인, 상점 심사자 접근, 사업자등록증은 확인하지 않았다. `mode:test` 응답만으로 실제 키가 유효하게 설정됐다고 판단할 수 없다.

## 결제 경로의 제약

- `paymentServer.js`는 운영 빌드의 테스트 키 신규 주문·승인과 테스트 이용권 조회를 차단한다. 현재 비활성 응답은 이 조건과 일치하지만 키·DB 설정을 직접 확인한 것은 아니다.
- `accountServer.js`는 Railway 비운영 환경에서 계정 기능을 차단한다. 기존 PR 미리보기 주소를 심사용으로 넘기는 것만으로 로그인·구매 경로가 열리지 않는다.
- 실결제는 아직 테스트 단계라는 사용자의 기존 지시를 유지한다. 이번 보완 요청만으로 라이브 결제를 켜거나 일반 가입 제한을 전면 해제하지 않는다.
- 심사용 경로는 `/subscription#purchase`와 `/en/subscription#purchase`의 테스트 위젯이다. 운영 환경의 `test_gck_` 공개 클라이언트 키만 사용하며, 실제 구매 `enabled` 값은 그대로 둔다. 로그인 없이 실제 상품의 금액·결제수단·테스트 결제창을 확인한다. 실제 주문을 생성하지 않고 승인 API·Pro 발급·운영 메일·구매 이벤트를 호출하지 않는다. 테스트 복귀 식별자는 전용 API에서 제거한 뒤 구독 페이지로 보낸다.
- 테스트 키가 설정돼 있지 않거나 토스에서 거부되면 창을 확인할 수 없다. 실제 위젯 확인과 결제 경로 자료 준비 전에는 재심사 준비 완료로 표시하지 않는다.

## 제출 전에 채울 사실

1. 등록증과 대조한 사업장 전체 주소, 공개 푸터 반영 URL.
2. 심사자가 사용할 실제 접속 URL과 로그인 절차. 계정 비밀값은 저장소·공개 문서에 남기지 않는다.
3. 위 접속 방법으로 상품 가격·이용기간·환불 안내·토스 결제창까지 진입한 검증 결과.
4. 테스트 결제의 인증·승인 범위와 운영 구매 권한에 영향을 주지 않는지 확인한 결과.

토스 요청 화면에는 재심사 요청 버튼이 있지만, 이 작업에서 요청을 제출하거나 토스에 메시지를 보내지 않았다.
