# 분석 품질·SEO 후속 실행 기록

2026-09-08. 최초 감사 수정 PR #807은 main에 머지됐다. 이 문서는 후속 제안 전체의 완료 선언이 아니라 이번 구현과 남은 범위를 구분하는 기록이다.

## 구현한 범위

- 추천 데이터 핸드오프·도치 실행 직전에 기존 상세 자격 검사 재사용. 유효 설치가 없지만 유효 액션이 있는 CSV의 oneOf 분모 선택도 수정했다.
- A/B에 계획 배정 비율·설계 확인·SRM, 선택 동등성 판독 추가. SRM 이상은 효과 결정과 결정 초안을 보류하고 다운로드에도 남긴다.
- MMM의 기존 식별·시간순 검증·공선성·건강도 실패를 예산 판단과 워크북에 함께 반영했다.
- ASA에 보고 기간 성숙도 선언과 적은 탭/설치 보류를 연결했다. 일별 총합에서 지연을 복원하지 않는다.
- Aha에 행동창과 결과 평가 시작 경계를 추가했다. 미선언은 탐색만, 경계 이상·기간 불명 행동은 제외한다. 원본 이벤트 시점 확인은 입력자가 해야 한다.
- 액션 생존 결론 가까이에 최고 해저드 시점의 실제 위험집단 수를 표시했다.
- 블로그 우선 5쌍(ASO·ASA·SKAN·광고 규격·Google 앱 캠페인)의 공식 출처와 수치·단정 문구를 수정했다. AI 검토자를 명시했다. 예산 증액 글에서도 고정 실험 기간·가상 경험의 단정을 수정했다.
- ASO 믹스 변화·ASA 성숙 후보·희소 포화도 합성 CSV 3개를 공개하고 관련 KR/EN 글에 재현 절차를 연결했다.
- KR/EN 용어사전 정의 아래 도구 링크, 상단 CTA 실제 노출, 글→같은 도구/언어의 업로드→결과 세션 계측을 추가했다. 공개 글 식별자만 30분 보관하며 CSV·파일명·헤더는 제외한다.

- 포화도 곡선 적합을 분석 게이트 뒤로 옮기고 표시 지표·선택 대상 변경 시 재적합을 없앴다. 포화도/예산에 명시 실행 기간 민감도와 별도 근거 CSV를 추가했다. 같은 총예산으로 전·후반을 재계산하되 표본·범위·채널·제약을 충족하지 못하면 비교 불가다. 기존 워크북에도 관측 상·하한 및 배분 제약·사용 관측 수를 보강했다.
- 대시보드/PVM/구성 변화 결론에 실제 기간·입력 행/집계 셀·분모·원본 통화·필터·전처리 입력 결측률을 추가했다. 복원 불가능한 결측률은 미집계이며 워크북 ANALYSIS_SCOPE에도 보존한다. 구성 변화의 표본 부족은 완료 이벤트에서 insufficient로 기록한다.

- 추천 카드에 명시적 상세 입력 검사를 추가했다. 초기 후보를 품질 검사 완료로 표시하지 않으며 KR/EN에 같은 차단·주의사항을 제공한다. 실제 실행 결과에도 상세 주의사항을 보존한다.
- 증분/브랜드 분석에 배정·관측 단위, 설계, 사전 기간·중단, 동시 변경 선언을 연결했다. 미확인/오염 조건에서는 실행 초안을 보류하고 추정 수치만 탐색용으로 남긴다. 집계 이항 홀드아웃은 무작위 사람/기기·중복 없는 단위 수가 필요하며 집단 배정의 불확실성을 검증했다고 주장하지 않는다. 선언은 기간/입력 변경 시 초기화되고 워크북·요약 CSV에 남는다.

- 생존 결과 가까이에 선택 horizon의 관측 완료·조기 이탈·조기 중도절단·지연 진입 실제 건수를 구분했다. 전체/세그먼트 근거를 CSV·워크북으로 제공하고 EN 다운로드 버튼도 번역했다.

## 검증 범위

- 생존 관측 근거 후속: 전체 390파일 3,049개, lint 오류 0, build 301페이지 통과. KR/EN 결론과 다운로드 메뉴, 조기 이탈/중도절단/지연 진입 분류를 검증했다.
- 추천 상세 품질 후속: 전체 388파일 3,043개, lint, build 301페이지, 기존 E2E 55개 통과. 실제 품질 확인 버튼을 추가한 KR/EN E2E 4개와 실행 후 주의사항 보존·입력 변경 초기화 스모크 19개도 통과했다.

- 전체 단위·스모크: 383파일, 3,012개 통과. 사용자의 기존 미추적 테스트도 실행에 포함되며 커밋에는 포함하지 않는다.
- build: 301/301 프리렌더 통과.
- Playwright: 320/768/1440·라이트 EN, axe 포함 55개 통과. 최초 실행은 새 ASA 패널로 기존 인접 DOM 선택자 3건 실패; 결과 영역 및 성숙도 입력의 실제 동작을 검증하도록 수정했다.
- Aha KR/EN 경계 전체 제외→분석 완료 insufficient→개입 초안 없음 회귀를 검증했다.
- 공통 입력 검사·SRM·동등성·MMM·ASA·Aha 순수 함수 및 실제 공개 CSV 자동매핑 검산을 실행했다.
- 증분 화면의 첫 조작이 이벤트 연결 전에 유실되는 경로를 재현해, 클라이언트 준비 전 탭/파일 입력을 비활성화했다. 기본 select도 방향키 이벤트를 반영하지 않는 로컬 Mac Chromium 검증 환경의 제약을 확인했다. 네이티브 방향키 메뉴 조작은 미실측이며 선택값 변경·Tab 포커스 검증과 구분한다.
- 증분/브랜드 후속 검증: 단위·스모크 386파일 3,034개 통과, 최종 카피 변경 후 증분 18개 추가 확인, lint 오류 0. Playwright 59개 통과(신규 설계·보류·포커스·axe 4개 포함). 홀드아웃 숫자의 라이트/다크 대비 미달을 테마 토큰으로 수정해 같은 axe 경로가 통과했다.
- Lighthouse·실제 Android 데스크톱 사이트/iOS Safari·Search Console/GA4 검색 성과 4주 비교: 미실측. 브라우저 에뮬레이션을 실기기 검증으로 세지 않는다.

## 제안 전체에서 아직 남은 작업

후속 검증 보강: PR #809 머지 이후 콘텐츠의 반복 단위 선언 시 행 무작위 Random Forest 비교를 내리는 처리를 추가했다. 이미 시작한 비교의 늦은 결과도 패널 언마운트로 표시/계측되지 않는다. 실제 단위별 교차검증 구현은 아직 남아 있다. 소재 피로 진단은 기존 노출 임계값·관측 기간을 충족한 항목만 비율 분모에 넣고, 부족한 근거를 건강함으로 표시하지 않는다. 워크북에도 항목별 보류 사유를 기록한다. 새로운 통계 모형이나 인과 추정은 추가하지 않았다.

|---|---|
| 공통 품질 | 추천 카드의 명시 상세 검사 및 실행 결과·다운로드 주의사항 공유 구현 |
| 포화도·예산 | 기간 민감도·근거 CSV 구현. 더 넓은 임의 기간 탐색/통계적 안정성 보장은 제공하지 않음 |
| 증분·브랜드 | 설계 선언·보류·내보내기 구현. 원본 배정 기록의 독립 검증과 집단 무작위 모형은 범위 밖 |
| 추세·유입·잠식 | 추적 정책·계절성·광고 중단의 비교 조건과 합성 반례 |

새 MMM 독립 페이지·범용 AI 페이지·무거운 통계 패키지는 원제안의 보류 결정을 유지한다. 검색 증가율·실제 과업 완료율은 운영 데이터를 측정한 뒤에만 보고한다.
