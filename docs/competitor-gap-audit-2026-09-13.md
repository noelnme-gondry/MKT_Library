## 3. 우선순위 (아스트라 제안 채택)

초판의 "병목 3개"는 폐기한다. 아래가 실측 가능한 순서다.

1. **공개 출시 준비** — 결제·계정 접근 제한의 **운영 의도를 먼저 확인**하고, 실제 구매·복원·메일 동작을 검증한다. (코드 문제가 아닐 수 있다)
2. **재사용 병목 측정** — 실제 CSV로 `첫 결과 → 저장 → 다음 주 업로드`를 밟아 **어디가 끊기는지 관측**한다. 추론이 아니라 측정.
3. **입력·자동화 설계** — 2에서 나온 실제 반복 데이터 소스를 기준으로 연동 범위를 정한다. 커넥터를 먼저 고르지 않는다.
