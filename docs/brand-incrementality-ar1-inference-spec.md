# 브랜드 캠페인 ITS — AR(1) 불확실성 계약

상태: 구현 대상. 적용 범위: `v2-migration/src/utils/brandIncrementalityMath.js`의 브랜드 캠페인 ITS(5-24).

## 결정

브랜드 ITS의 기본 95% 구간은 Newey–West HAC가 아니라 **선형 사전추세 + 정상(stationary) AR(1) 잔차** 구조모형으로 계산한다. 짧은 사전기간에서 랙 절단 HAC가 불안정하고, 결과 카드의 불확실성을 과소평가할 수 있기 때문이다.

HAC는 삭제하지 않는다. 동일 사전기간에서 계산한 참고 표준오차·랙·추정 AR(1)만 진단에 보이며, 결과 카드·CI·p값의 근거로 사용하지 않는다.

## 추정 계약

1. 사전기간 OLS 잔차로 AR(1) 계수 `rho`를 추정하고 `[-0.98, 0.98]` 범위로 제한한다.
2. 추정 `rho`로 Prais–Winsten 변환을 적용해 `y = intercept + slope * time + e`를 GLS 적합한다. 결과의 반사실은 이 GLS 사전추세의 무조건부 평균이다. 마지막 사전 잔차를 미래 평균에 더하지 않는다.
3. 혁신분산은 변환 잔차제곱합을 `n - 3`으로 나눈다. 절편·추세·추정 rho를 썼음을 반영한 보수적 자유도다.
4. 사후 m기간 잔차합의 분산은 정상 AR(1) 공분산을 닫힌 형태로 합산한다.

```text
gamma0 = sigmaInnovation² / (1 - rho²)
Var(sum(e_post)) = gamma0 * [m + 2 * sum_{k=1..m-1}(m-k)rho^k]
Var(counterfactual sum) = postX' Var(beta_GLS) postX + Var(sum(e_post))
```

5. 95% CI와 p값은 `df = n - 3` Student-t를 사용한다. `n <= 3`, 분산 0, 특이 설계행렬은 `NOT_IDENTIFIED`다.

## 표시 계약

- CI가 0을 배제해도 “증분 확정” 또는 인과 증명으로 표현하지 않는다.
- 사전기간 50 미만: **탐색적**. AR(1) 가정에 민감하므로 증분 확정 근거로 사용할 수 없다.
- 사전기간 50~149: **가정 민감**. 관찰 증거이며 더 긴 사전기간 또는 통제군을 권한다.
- 150 이상: **참고 가능**. 그래도 AR(1) 가정 및 통제군 부재 한계는 유지한다.
- 위 기간대는 보장 임계값이 아니라 표시 강도를 정하는 보수적 가드레일이다. 실제 잔차구조가 AR(1)이 아니면 구간도 달라질 수 있다.

## 검증

- 고정 시드 혁신항으로 만든 AR(1) 합성열을 사용한다. `Math.random`은 사용하지 않는다.
- 알려진 AR(1) 공분산 합산과 구현값을 비교한다.
- rho가 커질수록 AR(1) 표준오차가 단조 증가하는 성질을 고정 fixture에서 검증한다.
- HAC는 참고값임을 확인하고, 결과 CI의 `confidenceMethod`는 `ar1_prais_winsten`이어야 한다.
- 거짓양성률 몬테카를로는 CI의 flaky 테스트가 아니라 오프라인 검증 스크립트에서만 점검한다.
