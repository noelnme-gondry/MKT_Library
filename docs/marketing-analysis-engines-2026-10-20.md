## 구현 경계

- 새 정의는 `lib/advanced-marketing/` 정본에서 라우트·필드·가이드·카탈로그에 파생한다. 이질적인 데이터 단위는 별도 CSV 그룹으로 격리한다.
- 계산은 `utils/advanced-marketing/`의 순수 모듈에 둔다. 분석 게이트 이후 전용 worker에서 실행하고 취소·재업로드·라우트 변경 시 오래된 결과를 폐기한다.
- 날짜·관측 종료·무작위 배정·사전 변수·공통 ID 등 데이터만으로 확인할 수 없는 사실은 사용자 선언으로 받는다. 예시는 합성 데이터의 실제 설계를 함께 제공한다.
- 표본 부족, 특이 행렬, 최적화 실패, 불충분한 사전 적합, 통화 혼합, 중복 키, 잘못된 날짜·숫자를 정상이나 0으로 대체하지 않는다.
- 유의하지 않은 결과는 효과 없음이 아니다. 예측 구간·모수 불확실성·위약 참조 범위는 이름과 가정을 구분한다.
- 신규 분석 경로에는 기존 공용 셸, 업로더, 결론 카드, 표·그림·다운로드를 사용한다. 기존 도구에 새 엔진을 끼워 넣거나 과거 결과를 바꾸지 않는다.

## 데이터와 해석의 경계

`fixtures/customer-ledger.json`은 실제 고객이 없는 400명·1,516행의 합성 원장이다. NumPy 고정 seed 20261021로 비계약 구매율/이탈과 금액 이질성을 만든 뒤 정적 JSON으로 고정했다. 런타임 난수나 서버 계산을 사용하지 않는다. 다른 도구의 예시도 고정된 수식과 가명 ID만 사용한다.

새 도구의 입력 한도는 기본 50,000행이며 선택 과제·지역 패널은 20,000행이다. CLV는 30~5,000명·재구매 20명 이상, 합성 대조는 4~25지역·사전 35일/사후 7일 이상, 상품 연관은 300상품/장바구니 100종까지다. 잘못된 입력·중복·통화 혼합·수렴 실패·수치 범위 초과는 오류로 보류한다.

CUPED는 단일 사전 공변량 ANCOVA2, CRM은 사전 세그먼트 두 집단 평균 모형, 컨조인트는 수치 속성의 조건부 로짓이다. 지역 실험은 사용자가 사전에 고른 한 처치 지역의 합성 대조이며 자동 시장 선택이나 GeoLift 전체 복제는 아니다. 도달은 공통 ID가 있을 때만 정확한 합집합을 계산하고, 유입 이상을 부정행위로 판정하지 않는다. 상세 통계 가정과 불확실성의 범위는 각 KO/EN 결과에 표시한다.
