## 공통 문제와 처리

1. **제목과 보조 문구가 과대** — `ToolIntro`과 sticky 제목을 대시보드와 같은
   compact scale로 낮췄다. 본문보다 제목이 시선을 과도하게 잡아먹지 않는다.
2. **긴 탭/필터가 좁은 화면에서 잘릴 수 있음** — 전 분석 화면의 탭을 가로 스크롤
   가능하게 하고, 버튼은 줄바꿈 대신 읽을 수 있게 보존한다.
3. **근거 텍스트가 표·차트 폭을 전부 차지** — 설명/콜아웃 최대 폭과 행간을 통일해
   숫자·차트보다 설명이 먼저 튀지 않게 했다.
4. **정보 밀도 불균일** — 섹션 간격, 제목 하단 여백, 콜아웃 padding을 전 도구에
   공통 적용한다. 계산·데이터·차트 값은 바꾸지 않는다.
