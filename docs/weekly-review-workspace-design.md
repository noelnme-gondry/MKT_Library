# 주간 운영 검토 화면

사용자 요구: 도치 업로드·프로젝트 설정·주간 리뷰를 유료 구매를 검토할 만큼 전문적인 업무 경험으로 개선한다. 현재 제공되지 않는 결제나 분석을 약속하지 않고, 실제 관측·목표·캠페인 비교·저장한 결정·공유 자료의 깊이를 높인다.

## 설계

- 색: 기존 토큰의 다크 바탕 #121212, 본문 #f8fafc, 강조 #adc6ff / 라이트 바탕 #f4f5f7, 본문 #111827, 강조 #2b6cb0. 코드에서는 hex 대신 의미 토큰을 쓴다.
- 글꼴: 기존 Wanted Sans 유지. 본문 14~16px, 섹션 제목 18px, 결론 28~32px, 숫자는 tabular-nums. 작은 영문 장식 라벨을 추가하지 않는다.
- 구도: 왼쪽 정렬. 프로젝트 기준을 한 구역에서 편집하고, 결과가 생기면 요약 줄로 접는다. 결론과 목표 차이를 먼저 읽고 캠페인 비교로 내려간다. 보고서는 메모장 대신 독립된 문서로 보여준다.

```text
도치: 파일 선택 → 컬럼 확인 → 분석 결과 / 주간 리뷰로 이어가기
주간 리뷰
  프로젝트 기준 [이름 / KPI / 목표 / 기간]
  이번 주 결론 + 실제 비교 기간
  목표 대비 차이 | 비용·전환·선택 KPI
  캠페인별 전후 비교 [정렬·검색·결정 대상으로 선택]
  산술 분해 근거 / 지난 결정 검토 / 이번 결정
  팀 공유 보고서 [복사 / 인쇄 / 보고서·비교표 다운로드]
```

검토: 지표 카드를 늘리는 것만으로는 전문성이 생기지 않는다. 가장 눈에 띄는 영역은 실제 목표와 관측 차이로 한정하고, 캠페인 표·결정·보고서가 같은 값을 공유하도록 한다. 기간·통화·KPI가 바뀌면 다른 기준의 목표를 재사용하지 않는다. 비용당 결과 비율을 평균하지 않고 기존 합산·지표 함수를 재사용한다.

## 수용 조건

- KR/EN 동일 기능, 320/768/1440과 라이트/다크에서 핵심 조작 가능.
- 도치의 이미 올린 CSV로 주간 리뷰에 이동하고 다시 업로드하지 않는다.
- 프로젝트 설정은 KPI·단위·목표·기간이 같은 구역에 있으며 저장 성공/변경/실패 상태를 구분한다.
- 없는 매출·전환·과거 캠페인 값은 0이나 정상으로 채우지 않는다.
- 목표와의 산술 차이를 절감 예측·인과효과·자동 추천 예산으로 표시하지 않는다.
- 화면·공유 보고서·비교 CSV의 실제 수치·범위가 일치한다.
