# 분석 보고서 유료화와 결제 연결 작업

2026-09-09 · 작업 브랜치 `codex/paid-analysis-workspace`

## 사용자 확정 범위

- 무료 분석 실행은 유지한다. 분석 결과 다운로드는 이용권 구매자에게 제공한다.
- 보고서는 Word 문서와 수식·차트를 포함한 Excel 두 형식이다. 프로젝트 백업은 사용자의 데이터 이동 수단으로 유지한다.
- 5,900원 1개월 이용권이며 자동 갱신은 없다.
- 홈·주간 리뷰·프로젝트 보관함의 디자인과 이동 경로를 통일한다.
- 토스 심사는 사용자가 진행했다. 제공한 개발자센터 링크는 테스트 키 페이지다. 라이브 상점 활성화 상태는 미확인이다.

## 구현 및 검증

- 홈의 두 CTA와 보조 링크 크기, 보관함 진입점, 프로젝트 생성·복원 화면 개선.
- 공통 결과 다운로드 구매 팝업, Word 생성기, Excel 네이티브 차트 연결. 추가 CSV/PNG와 주간 리뷰 다운로드도 이용권 확인. 입력 템플릿·사용자 프로젝트 백업·결정 기록 이동은 무료 유지.
- 토스 SDK(사용자 클릭 시 로드), 주문 저장·금액 검증·멱등 승인·이용권 복원·취소 재조회 구현. 결제 식별자는 추적 페이지에 도달하기 전에 URL에서 제거한다.
- 최종 3,371개 테스트·lint·프리렌더 빌드 통과(사용자 미추적 테스트 6개 포함). 브라우저 121개 중 최초 106 통과·2 의도적 생략·13 실패였으며, 사업자 푸터 대비와 구매자 테스트 전제 수정 후 관련 26개 전부 통과.
- 주간 리뷰 CPI·ROAS·전환 수는 실제 리뷰 파이프라인에서 집계 입력과 Excel 수식까지 검증했다. 승인 직후 늦게 도착한 초기 조회가 구매 상태를 지우지 않는 경쟁 조건도 검증했다.
- Word/Excel 실제 파일을 생성하고 별도 Python 문서·워크북 파서로 재검사했다. Excel 네이티브 차트 1개, 수식, 머리글 스타일, 고정 행을 확인했다. Microsoft Word/Excel 자체 렌더는 미실측.
- Next.js 16.3.4, sharp 0.35.4, js-yaml 3.15.2로 보안 패치. npm audit 0건.

## 완료 전에 필요한 검증과 작업

1. 실제 PostgreSQL에 스키마 적용과 서버 키 설정, 상점 테스트 결제·취소·복원 검증. 현재 자동 테스트는 DB/토스 응답 대역이며 실측과 구분한다.
2. 실기기 iOS Safari·Android Chrome 데스크톱 모드·Lighthouse 및 Microsoft Office 렌더는 미실측.
3. Word에는 현재 생성된 화면 차트를 담는다. Excel은 관측 시리즈에서 차트를 재구성하며 플러그인 주석을 완전히 재현하지 않는다. 다른 단위의 축은 분리한다. 복잡한 통계 모델은 사이트에서 재추정하며 원본 변경만으로 전체 파이프라인이 재계산되지 않는다.
4. 실결제는 상점 활성화·환경 설정·실제 승인 검증 후 열어야 한다. 상세 운영은 `docs/toss-report-pass-operations.md`.
