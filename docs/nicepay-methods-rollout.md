# 추가 결제수단 운영 설정

현재 상품은 자동 갱신 없는 1개월 이용권이다. 결제수단 확대는 정기결제 전환이나 환불정책 변경을 의미하지 않는다.

1. 나이스페이에서 가상계좌, 네이버페이 카드, 카카오페이, 휴대폰(디지털 콘텐츠) 사용 가능 여부와 계약을 확인한다.
2. 승인된 수단만 Railway `NICEPAY_METHODS`에 쉼표로 나열한다. 전체 승인 후 값은 `card,vbank,naverpayCard,kakaopay,cellphone`. 미설정 기본값은 `card`. 키 재발급은 임의로 하지 않는다.
3. 기존 `/api/payments/nicepay/webhook`을 해당 수단에도 등록하고 입금·취소 통보를 확인한다. 가상계좌 입금 완료는 서버가 PG를 다시 조회해 확인하며 클라이언트 통보만으로 권한을 부여하지 않는다.
4. 각 수단의 승인 → 이용권 → 전체 취소를 점검한다. 가상계좌는 발급 → 새로고침 후 계좌 안내 유지 → 입금 → 이용권 활성화 순서를 확인한다. 실제 입금/취소는 아직 검증하지 않았다.
5. 네이버페이는 카드 전액 방식이다. 포인트/머니 결제 지원으로 광고하지 않는다. 휴대폰 결제는 콘텐츠 구분을 전송한다.

기존 고객에게 공지한 환불 조건을 소급해 축소하지 않는다. 현재 게시된 정책은 7일 이내 사용 여부 무관 전액 환불, 이후 미사용 기간 일할 환불이다. 향후 정책 변경은 법정 청약철회, 미제공 기간, 하자·오결제 처리와 구분해 별도 검토한다.
