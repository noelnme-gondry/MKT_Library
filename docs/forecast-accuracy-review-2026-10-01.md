# 미래 예측 정확도 검토 — 2026-10-01

## 목적과 재현

사용자가 지적한 평평한 미래 예측, 최근 13주 하락을 놓친 검증 곡선, 과도한 예산 소수점을 확인했다. `/tools/marketing-forecast?example=1`의 response 예시 132주(2023-01-02~2025-07-07), 기본 13주 예측을 사용했다. 실제 고객 CSV에 대한 정확도 증명은 아니다.

## 확인한 결과

| 항목 | 결과 |
|---|---:|
| 봉인 검증 첫 주→마지막 주 실제 변화 | -20.8% |
| 같은 구간 모델 변화(실제 비용 입력) | -7.2% |
| 실제 비용 입력 wMAPE | 12.2671% |
| Organic / Paid wMAPE | 14.6653% / 7.4660% |
| 최근 평균 예산 고정 wMAPE | 15.8735% |
| 검증 직전 실적을 계속 유지한 기준선 wMAPE | 15.8569% |
| 실제 비용 입력 모델의 평균 오차(예측−실제) | 약 +768명 |

최근 하락을 과소예측한다. 실제 비용을 미리 주는 검증과 미래 예산을 고정하는 예측은 다른 조건이다. 고정 예산 오차에는 실제 지출 경로와 가정의 차이도 포함되므로 순수한 모델 오차라고 부르지 않는다. 고정 예산 모델이 단순 기준선을 능가한다는 근거는 이 구간에서 없다.

평평함은 렌더링 오류가 아니다. 미래 주별 예산이 같고 선택된 모델의 감쇠 추세·최근 평균 혼합·약한 계절 성분이 안정 수준으로 수렴한다. 실제 성과가 안정될 것이라는 보장은 아니다. Organic 선택은 최근 52주/감쇠 추세 + 최근 13주 평균 혼합, Paid 선택은 expanding/분기 성분 + 최근 26주 평균 혼합이다.

후보 수를 40→80→160으로 늘린 진단의 봉인 전체 오차는 12.27→12.29→13.82%였다. 후보 확대만으로 개선되지 않아 적용하지 않았다. 이 진단 결과로 모델을 다시 선택하거나 봉인 구간을 튜닝 자료로 사용하지 않았다. 연간 후보의 충분한 학습·독립 검증 조건도 낮추지 않았다.

## 반영

- 미래 예측에 고정 예산 조건과 예측 범위를 표시한다. 자연스러워 보이도록 임의로 곡선을 흔들지 않는다.
- 검증에 실제 변화/예측 변화/평균 오차, 실제 비용 입력과 고정 예산 조건의 별도 점수·곡선을 표시한다.
- 고정 예산 재현은 봉인 구간 전에 선택된 후보만 이전 이력에 재적합한다. expanding 정규화 페널티는 그 학습 행 수로 환산한다. 후보를 재선택하거나 미래 비용·실적을 사용하지 않는다.
- 실제 비용 입력 점수가 통과하더라도 고정 예산 검증이 10% 기준을 넘으면 예산 시나리오 인증을 열지 않는다. 지원하지 않는 모델 분기의 고정 예산 점수는 추정 불가(null)로 둔다.
- 예산 입력은 USD 소수 2자리, KRW 정수로 표시한다. 읽거나 포커스·블러하는 것만으로 계산 값을 반올림해 저장하지 않는다.
- KO/EN 동등 반영. `mmmMath.js` 엔진과 선택된 미래 점예측은 변경하지 않았다.

주요 파일: `MarketingResponse.jsx`, `marketingResponseModel.jsx`, `globals.css`, `lib/analysis-results/forecastAccuracy.js`와 해당 골든·스모크 검사.

## 검증 및 한계

검증 결과는 작업 종료 후 아래에 기록한다. 실제 고객 CSV·모든 구조 모델·모든 미래 예산 경로의 정확도를 검증한 것은 아니다. 모델 정확도 자체가 개선되었다고 주장하지 않는다.

브랜치 `codex/result-autonomy-pilot-fixes`. 기존 사용자 변경과 미추적 파일을 보존하며 커밋·push·배포하지 않는다.

## 후속 요청 — 예측 결과 자체의 수정

앞선 작업은 오차를 드러냈지만 점예측을 바꾸지 않았다는 사용자 지적에 따라 입력 해상도 선택 경로를 추가 점검했다. 위의 '선택된 점예측 변경 없음'은 앞선 작업 시점의 기록이며, 아래 수정은 실제 점예측을 바꾼다.

### 원인과 적용

Organic 예측 입력을 Brand/Performance 합계로 강제 변환하고 있었다. 서로 다른 채널 반응이 합계 안에서 소실될 수 있다. 채널별 원입력 모델을 별도 후보로 적합하고, 기존 합산 모델과 **동일한 이전 outer 검증 구간 3개 이상**에서 비교한다. 봉인 최신 구간은 선택에서 제외한다. 오차 개선이 실질 동률 폭(max 0.1%p, 합산 오차의 2%)보다 클 때만 채널별 모델로 전환한다. 비교 불가/동률/채널별 모델 악화 시 기존 합산 모델을 유지한다.

이 선택은 입력 해상도 선택용 개발 점수다. 개발 점수를 최종 일반화 정확도라고 주장하지 않으며, 마지막 구간 및 고정 예산 오차를 별도로 표시한다. Paid 모델, CSV 원자료, MMM 기여 엔진, 인증 임계값은 변경하지 않았다.

| 예시 데이터 검증 | 기존 합산 | 채널별 선택 후 |
|---|---:|---:|
| Organic 공통 이전 검증 4개 구간 wMAPE | 9.2069% | 6.5960% |
| 최신 13주 전체 wMAPE — 실제 비용 입력 | 12.2671% | 4.8275% |
| 최신 13주 전체 wMAPE — 최근 예산 고정 | 15.8735% | 15.7380% |
| 예측 첫 주→마지막 주 변화 (실제 -20.8%) | -7.2% | -14.1% |
| 고정 예산 미래 예측의 max−min/평균 | 약 0.3% | 약 5.8% |

고정 예산 오차 개선은 미미하다. '미래를 4.8% 오차로 예측한다'고 해석하면 안 된다. 최신 감사는 코드상 선택 입력에서 제외하지만 이미 관찰한 예시 데이터를 진단한 작업이므로 완전히 새로운 외부 평가 자료는 아니다. 실제 고객 데이터와 이후 실적 검증이 필요하다.

### 적용하지 않은 탐색

전년 동주 기준선의 이력 요건과 최근 수준 보정 후보를 별도 진단했으나 개발 선택/결과 개선을 얻지 못해 적용하지 않았다. [계절 naïve 방법의 정의](https://otexts.com/fpp2/simple-methods.html)를 참고했으며, 계절 곡선을 강제로 추가하거나 기존 연간 회귀 요건을 완화하지 않았다. `mmmMath.js`에는 최종 변경이 없다.

### 변경 파일과 검증

- 입력 해상도 선택: `lib/analysis-results/forecastOrganicResolution.js` 및 테스트.
- 배선/표시: `components/tools/marketingResponseModel.jsx`, `MarketingResponse.jsx`, `MarketingResponse.smoke.test.jsx`.
