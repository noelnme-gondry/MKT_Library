# 프로젝트 리뷰·전달 개선 검증

프로젝트 리뷰를 각 도구에서 저장한 판단의 검토 목록으로 연결하고, 결정 당시 근거 → 실제 관측·배운 점 → 별도 후속 결정의 흐름을 추가했다. 기존 수학 엔진은 변경하지 않았다.

## 확인한 문제와 수정

- 주간 효율 분석 위주의 진입에서 다른 도구의 결정이 묻힘: 현재 프로젝트의 실제 기록으로 도구별 검토 목록을 만들고 해당 도구의 기록 편집기로 연결한다.
- 판단 당시 화면의 수치·불확실성·비교 범위를 나중에 확인하기 어려움: 결정을 저장할 때 허용된 표시 근거만 기기에 보존한다. 과거 데이터는 근거를 만들어 채우지 않는다. 새 필드는 결정 CSV와 프로젝트 저장에 유지되지만 계정 메모 API로 자동 전송하지 않는다.
- 관측 이후 다음 행동과 이전 결정의 연결 부재: 저장된 관측에서 새 결정을 만들고 부모 기록을 연결한다. 이전 관측을 덮어쓰거나 오래된 기준값·비교 범위를 새 결정에 복사하지 않는다.
- 작성 중 데이터 변경 시 이전 초안과 현재 분석 근거가 섞일 위험: 초안은 유지하고 저장을 막아 현재 결과로 다시 작성할 수 있게 한다.
- Word 표의 6열 제한으로 주간 KPI·관측 상태가 누락: 식별 열을 반복해 모든 열을 나누어 표시한다. 첫 20행 제한과 전체 Excel의 차이를 명시한다.
- 수식만 있는 셀의 Word 출력이 비거나 객체 문자열이 됨: 실제 엔진에서 받은 계산값을 함께 보존한다. 계산값이 없으면 미보관으로 표시한다.
- 보고서의 판단 근거와 후속 행동이 약함: 미리보기·Word·Excel·복사 브리프에 실제 비교값·단위·저장한 결정·관측 이력·다음 검토 조건·해석 한계를 포함한다. 결정은 최근 20건, 관측 이력은 결정당 최근 5회를 표시하고 범위를 알린다.
- 수집 보고서 Word에 Markdown 구문을 문단으로 나열: 도구별 결론·범위·핵심 수치·불확실성을 구조화된 표로 전달한다.
- 공유 링크의 수치 설명·비교 범위 누락: 허용된 날짜·통화와 수치 설명·해석 주의를 추가한다. 원본 행·파일·필터 목록은 넣지 않는다. 기존 링크는 계속 읽는다.

## 검증

- 전체 단위·화면 테스트: 4,187 통과, DB 환경이 필요한 기존 2건 로컬 제외.
- lint 통과. 프로덕션 빌드 통과.
- 실제 브라우저 30건 통과: 320/768/1440 화면, KR/EN, 기기 저장 실패 후 재시도, 새로고침 복원, 기존 업로드·재방문 흐름, 새 결정 피드백 루프와 보고서 미리보기.
- 실제 생성 DOCX 내부 문서에서 13번째 열·수치·신뢰구간·배운 점 보존 검증. Excel KPI 수식과 보관 계산값 검증.
- 복사 실패 때 성공 이벤트를 보내지 않는 KR/EN 화면 테스트. 공유 링크 허용 필드·기존 버전 호환 검사.

## 범위와 한계

자동 기간 비교와 원본 도구 재실행이 필요한 검토를 구별한다. 모든 도구에 동일한 자동 성과 판정을 적용하지 않는다. 관측 변화는 인과효과가 아니다. 과거 기록에 없는 근거는 복원할 수 없다. 복사 성공·다운로드 요청은 실제 팀 공유나 업무 활용의 증거가 아니다. 운영 GA 수신·실제 전환율 상승은 이번 코드 검증으로 확인한 것이 아니다.
