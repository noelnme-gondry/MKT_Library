# MMM 실제 비즈니스 계절성 검증 전체 기록

## 0. 한 줄 결론

제공된 CSV에서 `RR`을 결과값으로 넣고 5개 계절성 후보를 비교한 결과, 최종 모델은 `annual-4`로 결정했다.

쉽게 말하면, 광고·이벤트·장기 추세를 먼저 떼어낸 뒤에도 매년 비슷한 모양으로 반복되는 RR의 흐름이 남았고, 그 모양을 4개의 파형으로 표현한 모델이 가장 잘 설명했다.

단, 이 결과는 현재 데이터가 103주이고 광고 채널끼리 움직임이 매우 비슷하므로 **분해·해석용 결과**다. 어떤 채널에 예산을 더 넣으라는 결론으로 사용하지 않도록 예산 기능은 계속 차단했다.

## 1. 사용한 데이터와 목표

- 파일: `MMM Data - MMM Data set (1).csv`
- 관측 기간: 103주
- 결과값(Y): `RR`
- 광고 채널: `brand_`로 시작하는 채널과 `performance_`로 시작하는 채널
- 이벤트: CSV의 명절·행사 열을 이벤트 신호로 사용
- 외부시장 지표: Android/iOS 시장 다운로드 열을 별도 업계 지표로 사용
- 참고 화면: Performance, Brand, Holidays & Events, Industry Trend, Seasonality, Trend를 분리한 분해 화면

목표는 “매 52주마다 자동으로 물결을 그리는 것”이 아니었다. 실제 RR의 움직임이 광고나 이벤트만으로 설명되지 않고, 여러 검증에서도 반복되는 경우에만 Seasonality로 표시하는 것이 목표였다.

## 1-1. 4개 개선 라운드 이전의 사전 비교

4개 개선 라운드는 이 사전 비교를 끝낸 뒤 시작했다. 아래 `annual-1`부터 `annual-4`까지는 개선 라운드의 결과가 아니라 **기존 계산 방식으로 후보를 먼저 전부 돌려본 기록**이다.

### 기존 자동 결과

기존 MMM은 103주 데이터를 자동 선택할 때 `annual-1`을 사용했다. 당시 선택 과정은 가장 단순한 연간 파형을 기본값으로 두고, 복잡한 후보를 최종 채널 단위에서 모두 다시 비교하지 않았다.

### 사전 후보 전체 비교

| 사전 후보 | 의미 | R² | RMSE | 잔차 ACF(1) | 판단 |
|---|---|---:|---:|---:|---|
| `none` | 계절성 없음 | 0.95087 | 665.0 | 0.594 | 계절성을 넣지 않은 기준선 |
| `annual-1` | 1년 파형 1개 | 0.96328 | 574.9 | 0.525 | 기존 자동 선택 |
| `annual-2` | 1년 + 반년 파형 | 0.96448 | 565.4 | 0.552 | 설명력은 조금 상승했지만 오차 이어짐은 악화 |
| `annual-3` | 1년 + 반년 + 약 17주 파형 | 0.97588 | 466.0 | 0.411 | 좋은 후보지만 `annual-4`보다 약함 |
| **`annual-4`** | 위 파형 + 약 13주 파형 | **0.98344** | **386.0** | **0.243** | 사전 비교에서 가장 강한 후보 |

### 사전 단계에서 추가로 확인한 변형

annual 후보만 바꾼 것이 아니라 다음 변형도 임시로 비교했다.

- Brand와 Performance 매체를 묶어서 계절성만 찾는 방식
- Brand/Performance를 묶은 `annual-1`·`annual-2`·`annual-3`·`annual-4`
- 외부시장 지표를 제외한 방식
- 이벤트 신호를 제외한 방식
- 외부시장과 이벤트를 모두 제외한 방식
- 연간 파형과 분기 파형을 조합한 방식
- 광고 효과 제한값을 약하게·강하게 바꾼 방식
- 최근 구간 예측에만 계절성을 사용하는 rolling 방식

이 사전 변형 비교에서 확인한 점은 다음과 같다.

1. `annual-4`가 참고 화면의 “완만한 상승 → 큰 하락 → 다시 상승 → 연말 하락” 모양에 가장 가까웠다.
2. 외부시장 지표를 빼도 계절성 후보가 유지됐다.
3. `annual-3` 이하 후보는 실제 RR의 큰 봉우리와 골을 충분히 표현하지 못했다.
4. 계절성을 복잡하게 만들수록 예측이 항상 좋아지는 것은 아니었기 때문에, 이후 4개 개선 라운드에서 rolling 검증을 추가했다.

따라서 4개 개선 라운드의 출발점은 `annual-1` 하나가 아니라, `none`부터 `annual-4`와 외부시장·이벤트·rolling 변형을 모두 확인한 상태였다.

## 2. 용어를 쉽게 풀면

| 화면·계산 용어 | 쉬운 뜻 |
|---|---|
| R² | 실제 RR의 움직임을 모델이 얼마나 설명했는지. 1에 가까울수록 설명력이 높다. |
| RMSE | 모델 예상값과 실제값의 평균적인 차이. 작을수록 좋다. |
| 잔차 ACF(1) | 모델이 설명하지 못한 오차가 바로 다음 주에도 이어지는지 보는 값. 낮을수록 빠뜨린 흐름이 적다. |
| BIC | 설명력과 복잡도를 함께 보는 점수. 너무 복잡한 모델에 벌점을 주며, 낮을수록 좋다. |
| WMAPE | 실제값이 큰 주의 중요도를 반영한 예측 오차율. 낮을수록 좋다. |
| rolling 검증 | 과거로 학습하고 그 다음 12주를 맞혀보는 과정을 여러 시점에서 반복하는 것. |
| 52주 상관 | 올해의 계절성 모양과 약 1년 뒤의 모양이 얼마나 비슷한지. 1에 가까울수록 모양이 반복된다. |
| BIC 개선 | 계절성을 넣었을 때 설명력이 좋아진 정도. 양수이고 클수록 계절성을 넣을 이유가 커진다. |
| 매체 상관 | 광고 채널들이 서로 비슷하게 움직이는 정도. 너무 높으면 RR 상승을 어느 채널의 공으로 돌릴지 알기 어렵다. |

이 표는 이벤트 열을 실제 이벤트 신호로 사용한 동일 조건 비교 결과다.

| 후보 | R² | RMSE | 잔차 ACF(1) | 최종 BIC | 3개 rolling 평균 WMAPE |

## 5. 요청 이후 추가로 진행한 4개 라운드

### 라운드 1 — 마지막 선택 기준의 오류 수정

#### 무엇을 했나

처음에는 Brand/Performance를 묶은 임시 화면에서 좋은 후보만 추린 뒤, 그 일부만 실제 채널 단위로 다시 계산했다.

#### 왜 했나

임시로 묶은 데이터에서 좋은 후보가 실제 채널을 복원했을 때도 좋은지는 별도 문제다. 이 두 순위가 다르면 잘못된 후보가 선택될 수 있었다.

#### 무엇이 바뀌었나

`none`부터 `annual-4`까지 모든 후보를 실제 채널 단위로 다시 계산하도록 변경했다. `finalBic`과 `finalDeltaBicVsNone`도 모든 후보에 대해 기록한다.

#### 결과

자동 선택이 기존 `annual-1`에서 `annual-4`로 바뀌었다.

동일 조건 기준 변화:

- R²: 0.96328 → 0.98344
- RMSE: 574.9 → 386.0, 약 32.9% 감소
- 잔차 ACF(1): 0.525 → 0.243, 약 53.7% 감소

---

### 라운드 2 — 미래 구간에서 무너지는 후보 제거

#### 무엇을 했나

각 후보를 과거 데이터로 학습한 뒤, 다음 12주를 맞혀보는 과정을 3번 반복했다. 계절성을 넣은 후보가 무계절 모델보다 WMAPE를 2%p 이상 악화시키면 후보에서 제외한다.

#### 왜 했나

전체 기간을 잘 설명하는 것만으로는 부족하다. 과거 데이터에만 맞는 복잡한 물결을 그리는 것일 수 있기 때문이다.

#### 무엇이 바뀌었나

`seasonalityRollingHorizon`, `seasonalityRollingMinTrain`, `seasonalityRollingMaxFolds`, `seasonalityRollingMaxDegradation` 설정과 rolling 검증 결과를 추가했다.

#### 결과

- 무계절 모델 평균 WMAPE: 1.619%
- `annual-4` 평균 WMAPE: 2.117%
- 차이: +0.499%p
- 허용범위: +2.000%p
- 판정: 통과

즉, 예측 오차가 무조건 개선됐다고 과장하지 않고, 분해에 사용할 수 있을 만큼 불안정하지 않은지 확인했다.

---

### 라운드 3 — 외부시장 지표 때문에 생긴 착시인지 확인

#### 무엇을 했나

외부시장 다운로드 지표를 포함한 모델과 제외한 모델을 각각 돌려 seasonality 후보가 같은지 비교했다.

#### 왜 했나

외부시장 지표 자체가 매년 비슷한 움직임을 가지고 있다면, 그 움직임을 RR의 진짜 비즈니스 seasonality로 잘못 볼 수 있다.

#### 무엇이 바뀌었나

외부시장 지표를 포함·제외한 두 조건의 후보가 일치할 때만 안정적인 seasonality로 인정하는 합의 검증을 추가했다. 화면 설명에도 이 검증을 표시하도록 바꿨다.

#### 결과

- 외부시장 포함: `annual-4`
- 외부시장 제외: `annual-4`
- 합의: 통과

최종 실행의 `controlConsensus`는 `true`다.

---

### 라운드 4 — 네 가지 검증을 하나의 최종 선택으로 통합

#### 무엇을 했나

다음 네 가지를 모두 통과한 후보만 최종 선택 대상으로 만들었다.

1. Brand/Performance를 묶은 상태에서 구조적인 개선이 있는가
2. 실제 채널을 복원해도 BIC가 개선되는가
3. 52주 뒤에도 계절성 모양이 반복되는가
4. rolling 검증과 외부시장 포함·제외 검증을 통과하는가

#### 왜 했나

한 가지 숫자만 보면 “복잡하지만 설명력이 높은 모델”이나 “예측은 잘하지만 화면 모양이 부자연스러운 모델”을 고를 수 있다. 목표가 분해 화면과 실제 비즈니스 해석을 동시에 만족하는 것이므로 여러 조건을 결합했다.

#### 최종 결과

`annual-4` 선택.

- 집계 단계 BIC 개선: 35.80
- 실제 채널 단계 BIC 개선: 65.41
- 52주 계절성 모양 상관: 0.99884
- 계절성 RMS: 686.19
- 계절성 표시 범위: 약 -1,013 ~ +1,888 RR
- 외부시장 포함·제외 합의: 통과

## 6. 최종 분해에서 표시되는 내용

최종 모델은 RR을 다음처럼 나눠 설명한다.

- **Trend**: 광고와 이벤트를 빼고도 장기적으로 움직이는 기본 수요
- **Seasonality**: 위의 검증을 통과한 반복 수요 흐름
- **Holidays & Events**: CSV에 직접 들어온 행사·명절의 영향
- **Performance**: 퍼포먼스 매체들의 기여
- **Brand**: 브랜드 매체들의 기여

최종 실행의 평균 기여값은 다음과 같다.

| 분해 항목 | 평균 RR 기여 |
|---|---:|
| Trend | 47,261.37 |
| Seasonality | -13.40 |
| Holidays & Events | 318.51 |
| Performance | 2,650.47 |
| Brand | 621.54 |

Seasonality 평균이 0에 가까운 것은 오류가 아니다. 계절성은 어떤 주에는 양수, 다른 주에는 음수로 움직여 전체 평균이 서로 상쇄되기 때문이다. 중요한 것은 평균값이 아니라 주별 물결의 모양과 반복성이다.

## 7. 실행한 테스트 전체 기록

### A. 합성 데이터 테스트

실제 CSV만 보면 “좋은 데이터에만 맞춘 코드”일 수 있으므로, 별도의 인공 데이터도 넣었다.

1. 100주 동안 실제 비즈니스처럼 연간 파형과 Brand/Performance 광고를 함께 만든 데이터
   - 목적: 96주 이상이면 계절성을 찾아야 하는지 확인
   - 결과: 계절성 검출, 52주 모양 상관 0.75 초과, 정상 통과

2. 추세와 불규칙한 잡음만 있는 데이터
   - 목적: 계절성이 없는데도 계절성을 만들어내지 않는지 확인
   - 결과: 계절성 미검출, `none` 선택

3. 104주 미만 데이터
   - 목적: 짧은 데이터에서 복잡한 계절성을 억지로 선택하지 않는지 확인
   - 결과: 자동 선택을 끄고 기존 설정을 유지

4. 외부시장 지표가 추가된 합성 데이터
   - 목적: 외부 지표를 넣어도 같은 비즈니스 계절성을 찾는지 확인
   - 결과: 합의 검증 통과

### B. 실제 CSV 테스트

임시 Vitest 실행 파일로 제공 CSV를 실제로 읽고 다음을 확인했다.

- 103행 정상 읽기
- `RR`이 결과값으로 들어감
- Brand/Performance 채널 분리
- 이벤트 열 사용
- 외부시장 지표 분리
- 5개 후보의 전체 적합도와 최종 BIC 비교
- 3개 rolling fold WMAPE 비교
- 외부시장 포함·제외 후보 비교

## 9. v2 검증 방식 적용 결과 — 실제 반복성 게이트

### 9.1 이번 라운드에서 바꾼 점

기존 MMM은 52주 간격으로 반복되도록 만든 모델 곡선과의 상관을 계절성 근거로 사용했습니다. 이 방식은 모델이 계절성을 넣었기 때문에 상관이 높아질 수 있습니다.

이번 라운드에서는 다음 순서로 바꿨습니다.

1. 계절성을 넣지 않은 기본 MMM을 먼저 계산한다.
2. RR에서 매체·추세·이벤트 등으로 설명되지 않은 잔여 흐름만 남긴다.
3. 2024년과 2025년의 같은 주차 잔여 흐름을 직접 비교한다.
4. 상관, 방향이 같은 비율, 최고·최저점 시기 차이를 함께 본다.
5. 이 실제 반복성이 약하면 annual-1~4 중 어떤 후보도 분해에 사용하지 않는다.

쉽게 말하면, “매년 같은 시기에 실제 RR이 다시 움직였는가?”를 먼저 확인하도록 바꾼 것입니다.

### 9.2 제공 CSV 결과

입력 파일: `MMM Data - MMM Data set (1).csv`

### 9.3 기존 MMM·annual-4와의 비교

기존 후보 비교에서는 annual-4가 가장 좋아 보였습니다.

annual-4는 과거 데이터 안에서 RR의 움직임을 더 잘 따라가므로 R²·RMSE·BIC만 보면 우수합니다. 그러나 이 값들은 “매년 반복되는 사업 계절성”과 “이번 기간에만 있었던 일시적 흐름”을 구별하지 못합니다.

v2의 개선점은 계절성을 없애는 것이 아니라, annual-4의 큰 연간 흐름은 유지하면서 짧은 파동일수록 더 강하게 눌러 일시적 움직임의 과대 귀속을 줄이는 것입니다.

### 9.4 v2 테스트 플랜과 맞닿는 지점

- **I-01 / S02**: 모델이 만든 52주 곡선 상관을 독립 증거로 쓰지 않고, 실제 연도별 잔여 RR을 비교했습니다.
- **I-02 / S03**: 103주는 강한 계절성 확정에 부족하므로, 결과를 강함으로 올리지 않았습니다.
- **I-03 / R03**: 분해용 계절성과 예측용 안정성을 분리하는 첫 번째 게이트를 적용했습니다.
- **I-05 / R04**: 외부시장과 이벤트를 포함·제외하고도 판정이 바뀌지 않는지 확인했습니다. 모든 조건에서 약함이었습니다.
- **S10 / S20**: 계절성으로 보이는 움직임이 매체·이벤트·추세를 제거한 뒤에도 남는지 확인했고, 남은 패턴이 반복되지 않았습니다.
- **I-11**: 통계적으로 설명되지 않는 경우 “효과 없음”이라고 단정하지 않고, 현재 데이터에서는 “반복성 증거 부족”으로 표시했습니다.

### 9.5 이번 라운드의 결론

이번 CSV에 대해 계절성을 완전히 제거하지 않습니다. **annual-4의 큰 연간 파형을 유지하되, 26주·17주·13주처럼 짧아지는 파동에 순서대로 더 큰 규제를 적용**합니다. 실제 연도 반복성이 약한 점도 추가 규제로 반영합니다.

이번 변경의 production 결과는 다음과 같습니다.

- 선택 후보: `business-harmonic-shrink`
- 계절성 강도 보정: `0.50`
- R²: `0.98344 → 0.98319`
- RMSE: `386.00 → 388.96`
- hard delete: 하지 않음

따라서 이번 라운드의 결과는 “계절성 없음”이 아니라 **“annual-4 기반 비즈니스 계절성 + 짧은 파동 차등 규제 + 반복성에 따른 보수적 축소”**입니다.

연도 데이터가 최소 3년 이상 쌓이면 같은 검증을 다시 실행하고, 그때도 상관·방향 일치·최고/최저 시기가 유지될 때만 cyclic smooth 또는 연도별 크기 변화 모델을 후보로 올립니다.

> 정정 기록: 2026-07-24 중간 실행에서는 반복성 hard gate로 계절성을 제거하는 결과를 잠시 만들었으나, 비즈니스 목표와 맞지 않아 폐기했습니다. 현재 구현은 반복성을 탈락 사유가 아니라 계절성 강도 조정 자료로 사용합니다.

### 10.3 최종 선택 이유

`business-harmonic-shrink`를 선택했다.

- annual-4 대비 BIC 차이는 `+0.54`로 사전 허용범위 `2` 안이다.
- rolling WMAPE는 `2.117% → 2.092%`로 `0.025%p`, 상대 약 `1.2%` 개선됐다.
- 4주 제거 형태상관은 `0.995`로 사실상 동일하다.
- 최고점 37주, 주요 최저점 16주·45주, 연말 반등 형태가 유지된다.
- 가장 큰 계절성 최고점은 약 `1,888 → 1,842`, 45주 최저점은 약 `-793 → -738`로 완화됐다.
- 화면 참고 이미지의 넓은 연간 흐름과 연말 전후 굴곡은 유지하면서, 짧은 파동의 과대 반응만 줄였다.

`none`의 rolling 오차가 더 낮은 것은 실제 예측 목적에서는 중요한 경고다. 그러나 이 테스트의 목적은 계절성을 삭제하는 것이 아니라 분해용 비즈니스 계절성을 만드는 것이다. 따라서 `none`은 예측 참고선으로 남기고, 분해 모델은 큰 BIC 개선과 높은 형태 안정성을 만족하는 규제형 annual-4를 사용한다.

### 10.4 쉬운 설명

기존 annual-4는 큰 물결과 작은 물결을 똑같이 믿었다. 새 모델은 1년짜리 큰 흐름은 살리고, 6개월·4개월·3개월처럼 짧아지는 흔들림은 점점 덜 믿는다. 그래서 계절성 그래프는 살아 있지만, 특정 몇 주의 튐을 매년 반복되는 계절성으로 과장하는 정도가 줄었다.
