# AEO 측정 기록

프롬프트 목록은 `docs/aeo-prompt-checklist.md`에 있고 **생성물**이다(`node scripts/aeo-prompts.mjs`).
이 폴더에는 **실제로 돌린 결과**만 월별로 남긴다.

## 왜 폴더를 나누나

체크리스트는 도구·문구가 바뀌면 다시 생성돼 덮어써진다. 기록을 거기 적으면 다음 재생성에
사라진다. 실제로 2026-08-19에 체크리스트가 17개→22개로 갱신됐다 — 도구 승격이 반영되지
않아 **측정 대상이 제품보다 낡아 있었다.** 측정 전에 항상 먼저 재생성할 것.

## 절차

```bash
node scripts/aeo-prompts.mjs                                   # ① 목록을 현재 제품에 맞춘다
cp docs/aeo-prompt-checklist.md docs/aeo-runs/$(date +%Y-%m).md  # ② 이번 달 사본을 뜬다
```

사본은 실행 전 준비물이며 측정 결과가 아니다. 기존 월별 파일이 있으면 덮어쓰지 말고 실행 날짜·회차를 파일명에 추가한다. 원문 응답과 상세 기록은 비공개 위치에 보관한다. 공개 저장소에는 승인된 요약만 남긴다.

## 실행 증거와 분모

플랫폼·로케일별로 분리하고 다음 항목을 함께 기록한다.

| 필드 | 기록 기준 |
| --- | --- |
| 실행 조건 | 실행 시각, 제품·모델 표시명, 검색 모드, 언어·지역, 새 대화 여부, 프롬프트 목록 커밋 |
| 요청 | 목록의 프롬프트 원문과 ID. 목표 URL·우리가 원하는 답은 질문에 추가하지 않음 |
| 상태 | `not_run`, `error`, `no_ai_answer`, `answered` 중 실제 상태 |
| 증거 | 응답 원문 또는 비공개 캡처 경로와 실제 인용 URL. 검색 결과 링크만 있으면 AI 답변 인용으로 세지 않음 |
| 판정 | 언급·공식 도메인 인용 각각 true/false, 부정확한 주장과 해당 근거. 미실행은 null |

- 실행률 = 실행 시도 수 ÷ 계획 수. 오류와 AI 답변 미노출을 별도로 보고한다.
- 언급률·인용률 = 해당 판정 true 수 ÷ `answered` 수. 답변 0개이면 **미측정**이며 0%가 아니다. 분모와 계획 대비 응답 수를 반드시 함께 적는다.
- 같은 플랫폼·로케일·프롬프트 집합·검색 조건끼리 비교한다. 일부만 실행했다면 전체 목록의 성과로 일반화하지 않는다. 목록 변경 시 공통 항목 비교와 새 기준선을 분리한다.
- 자체 웹 검색 도구로 도메인이 검색되는지 확인한 것은 검색 가능성 점검이다. ChatGPT·Claude·Perplexity의 실제 사용자 응답 결과를 대신하지 않는다.

## Search Console과 제품 행동은 별도 기록

Google의 [Search Generative AI 성과 보고서](https://developers.google.com/search/blog/2026/06/gen-ai-performance-reports)는 AI 검색 노출을 확인하는 별도 근거다. 보고서에서 제공되는 날짜·페이지·국가·기기별 노출을 같은 완료 기간으로 내보낸다. 일반 웹 성과 시트의 ‘검색 노출’ 탭이 비었다고 AI 노출이 0이라는 뜻은 아니다.

| 측정 | 데이터 | 이 데이터로 판단하지 않는 것 |
| --- | --- | --- |
| 검색 성과 | 일반 웹 보고서의 클릭·노출·CTR·순위 | 특정 AI 답변에서의 인용률 |
| Google AI 노출 | Generative AI 보고서의 실제 제공 항목 | 다른 AI 제품의 추천·인용 |
| AI 응답 표본 | 위 실행 증거 | 전체 사용자에게 보이는 점유율 |
| 제품 사용 | 검색 랜딩 → 도구 클릭 → 비데모 분석 완료 | 클릭 증가가 분석 품질·인과효과를 입증한다는 주장 |

GSC 쿼리·페이지 탭의 주변 합계만으로 쿼리→페이지를 연결하지 않는다. `customer acquisition`의 실제 랜딩은 **검색어 필터 후 페이지 보고서**로 확인한다. 익명화·집계 기준 때문에 탭별 합계가 다를 수 있다. 상세 시트와 계정 정보는 공개 저장소에 넣지 않는다.

## 기록하지 않는 것

- **추정치·기억에 의존한 값**. 실제로 돌리지 않은 셀은 비워 둔다. 채워 넣으면 그 달 추이가
  통째로 못 쓰게 된다(§8 — 데이터 없는 상태를 날조하지 않는다).
- 계정 정보·유료 플랜 여부 등 공개 저장소에 남기면 안 되는 것.

말할 근거가 없다 — 비교 대상이 없기 때문이다.
