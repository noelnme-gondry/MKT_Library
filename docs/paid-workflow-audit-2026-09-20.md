# Pro 구매와 결정 피드백 점검 — 2026-09-20

## 판단

유료 기능의 실체는 Word·Excel 파일 형식 자체보다, 분석 당시 근거와 실행할 행동을 보관하고 관측 결과를 후속 결정으로 연결하는 데 있다. 사용 의향·재구매율을 조사한 것은 아니므로 시장 수요나 가격 적정성을 검증했다고 표현하지 않는다.

## 확인과 개선

| 흐름 | 확인 근거 | 조치 |
|---|---|---|
| 구매자 식별 | 주문은 서버의 로그인 계정에 연결되지만 PG 요청에 이메일 누락 | 새 주문·재사용 주문 모두 서버가 검증한 이메일 전달, 결제 전 및 KR/EN 개인정보 안내에 고지 |
| 결제창 종료 | SDK 종료 안내 뒤 재결제 버튼만 남음 | 상태 확인 버튼, 확인 전 결제 버튼 숨김, 오류 문구는 새 시도 때 초기화 |
| 구매 가치 전달 | 기능 나열과 이용권 확인 문구 | 보고서 → 결정 저장 → 결과 검토의 실제 산출물 설명, 구매 후 작업·리뷰 진입 |
| 다운로드 | Word 문서 및 Excel 내부 XML 테스트로 수치·근거·차트·불확실성·관측 기록 포함 확인 | 기준값 0 누락 수정, 후속 행동 및 검토일을 공통 보고서 내용에 포함 |
| 프로젝트 리뷰 | CSV 없이 결정 목록 → 분석 결과 연결 → 관측 저장 → 다음 행동 → 중단/재설계 | 형제 컴포넌트 중복 key 수정 및 실제 브라우저 경고 회귀 검사 |
| 목표와 피드백 | 발행 도구 목록에서 목표 계약 커버리지 파생, 채널 기여 가설 → 오가닉 홀드아웃 목표 → 결과 관측 브라우저 검사 | 엔진과 통계 판정 변경 없음. 운영 목표 달성을 인과효과 검증으로 표현하지 않음 |

## 검증의 한계

브라우저 결제 테스트는 권한 응답과 결제 SDK를 모의한다. 실카드 승인·취소는 사용자가 수행했으며 전액 취소 완료를 알렸다. 운영 화면의 Pro는 체험 6일 남음으로 관찰했지만, 이번 코드로 다시 실결제한 것은 아니다. 실제 NICEPAY 취소 통보의 로그와 GA purchase 수신은 별도 대조가 필요하다.

Google 로그인 공개는 Railway 환경 변경과 운영 응답을 별도로 확인한다. 새 사용자의 Google 동의 화면 및 로그인 완료를 자동 테스트로 대체하지 않는다.

유료 체험에는 다운로드가 포함되지 않으며 구매 전 무료 샘플 파일과 분석 요약 미리보기를 제공한다. 원본 CSV와 프로젝트 전체는 기기 간 자동 동기화되지 않는다. 이 제한은 판매 화면에서 유지한다.

## 실행한 검증

- `npm run test:all -- --maxWorkers=2`: 4,239 통과, PostgreSQL 전용 3건은 로컬 DB 설정이 없어 건너뜀. 초기 병렬 부하에서는 기존 AssistantWorkspace 비동기 완료 대기 1건이 시간 초과됐고, 테스트 조건 수정 없이 재실행 통과.
- `npm run lint`: 통과.
- 프로젝트 리뷰·기여 분석 목표·결정 피드백·유료 작업 흐름 Playwright: KO 데스크톱/320px 모바일, EN 라이트 데스크톱 총 36건 통과. 중복 key 콘솔 경고 없음 회귀 검사 포함.
- 운영 공개 설정: NICEPAY/live/구매 가능, Google 계정 기능 활성, 이메일 가입 제한은 해제 전 상태 확인. 시크릿 값은 조회하지 않음.
