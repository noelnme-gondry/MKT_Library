# 프로젝트 리뷰 사용성 개선

대상: PR #898 이후 프로젝트 리뷰 감사. 통계 엔진과 기존 분석 골든값은 변경하지 않는다.

| 감사 항목 | 개선 |
| --- | --- |
| 효율 CSV가 필수처럼 보이는 첫 화면 | 결정 검토를 기본 진입으로 변경. 주간 성과 비교는 명시적 작업이며 기존 업로드·다음 결정 딥링크를 유지한다. |
| 읽기/편집 화면 분리 | 결정 행에서 단일 검토 상세를 연다. 관측·연결한 효과 근거·다음 행동을 함께 다루고 고급 일괄 편집에서는 중복 목록을 숨긴다. |
| 근거를 붙이려면 새 결정부터 저장 | 공통 분석 결과 카드에서 기존 결정에 직접 근거를 연결한다. 새 결정은 만들지 않는다. 저장 실패 시 선택과 원래 기록을 유지한다. |
| 무관한 근거 후보 | 지표가 맞고 확인된 조건이 충돌하지 않는 후보를 우선 표시한다. 지표·집단·기간을 나란히 보여주며 다른 후보는 명시적으로 펼친다. 조건 확인 후 연결한다. 누락 조건은 미확인이다. |
| 후속 폼 과밀 | 행동·목표·검토일을 우선 입력한다. 수치 목표·실험 설계와 유지 조건·검토 질문은 별도로 펼친다. 실험 대상·대조군·기간은 방법에 따라 표시한다. |
| 빈 목표의 통화 경고 | 유효 목표·실제 데이터·원본 통화가 있을 때만 불일치를 표시한다. |
| 관측 저장과 다음 행동 단절 | ‘관측 저장 후 다음 행동 정하기’가 저장 성공 후 후속 폼을 연다. 실패하면 초안을 유지한다. |
| 예정일 전 중단 불가 | 실행 취소·중단·설계 오류를 명시적 종료 사유로 보존한다. 조기 성공·실패로 판정하거나 성과 개선 집계에 넣지 않는다. CSV와 보고서도 사유를 보존한다. |
| 이전/다음 결정 이동 불가 | 연결된 결정으로 바로 이동하며 선택한 상세로 포커스를 옮긴다. 저장하지 않은 입력이 있으면 이동 취소가 가능하다. |
| 보고서 최근 20건 고정 | 도구·예정 검토일·결정 흐름을 선택한다. 연결된 이전 결정은 포함하고 포함/제외 건수를 알린다. 프로젝트 보고서는 선택한 전체 기록을 내보낸다. 일반 도구 보고서의 기본 한도는 유지한다. |
| 기기 저장/계정 메모 혼동 | 기기 프로젝트 저장을 먼저 설명한다. 저장 후 계정 메모 보관은 별도 선택 영역으로 접는다. 기존 로그인·Pro·동의 검증은 유지한다. |

검토 시점 필터와 도구별 접기 목록을 제공한다. 주간 비교로 명시적으로 보내는 기존 도치 동선은 해당 화면으로 직접 연결한다. 신규 프로젝트의 첫 리뷰는 도구 선택에서 시작한다.

## 검증과 한계

- 단위·컴포넌트: 조건 불일치/미확인, 순환 부모 연결, 필터 밖 이전 결정 보존, 25개 기록 전체 내보내기, 종료 사유 CSV 왕복·판정 제외, 직접 연결 시 결정 수 유지, 화면 전환 초안 보호.
- 브라우저: 기본 진입 → 직접 분석 연결 → 관측 저장 → 후속 결정 → 부모/자식 이동 → 조기 종료 → 새로고침 복원을 한국어 320/768/1440px와 영어 밝은 화면에서 검증한다. 기존 저장 실패·체험·만료 후 열람·주간 비교·보고서 경로도 회귀 검증한다.
- 자료는 로컬 가상 프로젝트와 테스트 CSV다. 실제 고객 사용성 조사, 운영 GA 전환·이탈 분석, 운영 고객 데이터 검증은 포함하지 않는다.
- 근거 연결은 실험 설계의 타당성이나 인과효과를 자동 검증하지 않는다. 자유 입력 기간/대상 표기가 다르면 명시적으로 확인해야 한다.
- 운영 목표 달성과 효과 근거는 별개다. 부분 회복량과 구간을 함께 읽으며 목표 미달을 카니발 없음으로 표현하지 않는다.
