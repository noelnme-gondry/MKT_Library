# Growth Opt Playbook 감사·개선 실행 결과

2026-09-09. 최초 감사와 분석 품질 후속은 PR #807, #809, #810, #813–#822로 머지했다. 이 문서는 마지막 블로그 전수 검토와 공개 예제 검증을 포함한 최종 기록이다. 원 제안은 `analysis-quality-seo-plan-2026-09-07.md`, 단계별 증거는 `analysis-quality-followup-2026-09-08.md`에 보존한다.

## 범위와 측정의 구분

- 발행 블로그 **KO 47편·EN 47편의 원문 본문·FAQ·짧은 답을 전수 열람**했다. 초안과 템플릿은 발행 전수에서 제외했다. 실제 검토일과 AI 보조 검토자를 남겼으며, 본문 변경이 없는 글의 수정일은 올리지 않았다.
- 코드 전체를 모든 줄 감사했다고 주장하지 않는다. 아키텍처·제품 정본에서 출발해 라우트/그룹/매핑/분석 게이트/공개 메타 계약을 검사하고 의심 소비처를 직접 읽었다. 계산 엔진·기존 골든값은 변경하지 않았다.
- 공식 출처 확인은 **주장별 표본 검증**이다. Apple·Google·TikTok·ASA의 해당 원문을 확인했다. Meta 도움말 일부는 로그인에 막혀 최신 요건을 확인하지 못했다. 검토 표시는 모든 외부 정책을 독립 검증했다는 인증이 아니다.
- 브라우저 결과는 Playwright Chromium이다. 사람 대상 과업 완료율, 첫 화면 이해 시간, 실제 읽다 멈춘 문장은 **미실측**이다. 자동화 통과율을 실제 사용자 성공률로 바꾸지 않는다.
- 라이트/다크·320/768/1440 검사 및 axe의 범위는 테스트에 포함된 화면이다. 모든 301페이지의 모든 상태에 대한 접근성 인증은 아니다.
- CSV 서버 전송은 추가하지 않았다. 기존 선택 가능한 기기 저장의 기본값·90일 정책은 제품 정본에 맞춰 안내하며, 메모리 전용으로 오인시키던 카피를 수정했다.

## 과업별 확인 기록

아래 단계 수는 자동화의 주요 사용자 행동 수다. 페이지 대기·코드 단언은 제외하며 통화 선언/안내 확인이 있으면 단계가 추가된다. 실제 사람의 소요 시간과 스크롤 양은 미실측이다.

| 과업 | 확인 경로 / 막힘·되돌아감 / 문장·결과 / 단계 |
|---|---|
| 1·3 홈→도구·데모 | 홈 첫 방문 안내 닫기→상황별 도구 목록→대시보드→예시 데이터→데모 안내의 나중에→결론→결과 받기→XLSX. 데모는 별도 분석 클릭 없이 결과가 열리는 기존 동작이다. 320px에서 고정 안내창에 막힌 경로를 수정했다. 데모 안내는 예시임을 밝히는 기존 추가 단계다. 주요 행동 5회(안내 닫기 포함 6회). |
| 2 업로드→추천→결과 | `/start`→CSV→원본 통화→매핑 안내 확인→상세 품질 검사→대시보드 상세. KO/EN 추천에서 결과 전달을 검증한다. 매핑 강제 재입력·재분석 없이 결과 열림. 주요 행동 5회. |
| 3 직접 CSV→다운로드 | 대시보드→CSV→통화/안내→분석→결론→XLSX. 원본 시트·실제 수식 확인, 내보내기 동안 fetch/XHR 0건. 주요 행동 4회+통화/안내. |
| 4 글→도구 | ASO·ASA·예산 증액 글→공개 CSV 다운로드→동일 언어 도구 링크→파일 업로드→분석→결론→결과 다운로드. ASO 34→16%는 믹스 변화, ASA는 성숙도 미확인에서 보류 후 선언, 포화도는 0/24 보류. 주요 행동 6회+통화/안내/ASA 선언. |
| 5 주간 검토 | 대시보드 결과→결정 펼치기→다음 검토로 저장→주간 검토→저장된 기록 1개. 입력 변경 후 이전 보고서의 stale 상태도 별도 확인. 저장 이후 주요 행동 3회. |
| 6 영문 대칭 | EN 홈·데모, EN 진입 추천, EN 글→3개 도구→내보내기 경로를 보강했다. 영문 짧은 답·FAQ가 한국어의 잘못된 주장까지 복제하지 않도록 함께 정정했다. |

빈 상태·빈 CSV·무관한 헤더의 필수 미매핑을 별도로 검증한다. 실제 플랫폼 헤더는 `Date/Source Type/Impressions/Product Page Views/Total Downloads` 및 Apple Ads 검색어 파일을 사용한다. 자동화에는 실제 사용자 ‘읽고 멈춤’이 없으므로 이를 지어내지 않는다.

## 검증 결과

- 단위·스모크: 392파일, **3,078개 통과**. 사용자 미추적 테스트도 집계에 포함되며 커밋하지 않는다.
- 린트: 오류 0. 빌드: **301/301 페이지 프리렌더 통과**.
- 전체 Playwright: **91개, 재시도 없이 통과**. 320/768/1440 및 light EN, axe 포함.
- 공개 예제: KR 320/768/1440·light EN **12경로** 다운로드→분석→내보내기 검산·axe 통과.
- 980px·터치·데스크톱 레이아웃: **12경로 확인**. 11개 통과 후 프로젝트 이름으로 테마를 강제하던 테스트 설정을 고치고 EN 진입 1개 재검증 통과. 실제 Android가 아니다.
- 새 테스트의 버튼명·오류 문구·데모 안내창·추천 순서 가정은 실제 DOM에 맞췄다. 이 실패들을 제품 결함으로 세지 않는다. 320px 고정 안내창 가림과 ASO 대비/판정은 실제 결함이다.
- 로컬 배포용 빌드에서 **EN 홈→데모→XLSX 통과**. 980px, coarse=true, light=true, 지연 200ms·다운로드 200,000B/s·업로드 100,000B/s. 자동화 경과 16.1초, 다운로드 오류 없음. 사람의 읽기 시간은 포함하지 않는다.

### 배포용 빌드의 JS 로딩 표본

1440px 새 컨텍스트에서 H1/업로더 준비까지 수신한 script 응답을 센 **6라우트 표본**이다. 개별 응답의 gzip 합은 CDN 실제 전송량·캐시·Brotli 크기와 다르며, 모든 지연 모듈이나 라우트 전체 번들 크기가 아니다.

## 추가 분석 도구·SEO 투자 결정

- **기존 도구 안에 도입 완료:** 상세 입력 검사, SRM·선택 동등성, 전환 성숙도 선언, 행동/결과 창, 생존 관측 근거, 기간 민감도, 시간·반복 단위 분리 검증, MMM 기준선 비교, 설계·동시 변경 보류 및 근거 내보내기.
- **새 독립 MMM·범용 AI 도구·무거운 통계 패키지는 보류 유지:** 기존 계산을 대체해 더 좋은 독립 검증 결과를 내는 근거가 없다. 기능을 늘리는 것을 분석 품질 개선으로 세지 않는다.
- **블로그 개선 반영:** 기존 47쌍의 산술/정직성, 3개 공개 실행 사례, 내부 도구 연결·정의 CTA, 한영 메타·답변 정합. 검색 키워드만 바꾼 새 글 대량 작성은 하지 않았다.
- **운영 성과 미실측 — 필요한 것:** Search Console·동의된 GA4의 동일 기간 4주 이상 데이터. 언어·글별 검색→도구→업로드→결과를 비교하되 CSV 원본·파일명·헤더·셀 값은 수집하지 않는다. 검색 증가율이나 사람의 과업 완료율을 현재 보고할 수 없다.

## 출처와 미실측

주요 공식 근거: [Apple 지표 정의](https://developer.apple.com/help/app-store-connect-analytics/reference/metrics-definitions), [Apple PPO](https://developer.apple.com/app-store/product-page-optimization/), [Apple Ads 구조](https://ads.apple.com/app-store/best-practices/campaign-structure), [Google Play 실험](https://support.google.com/googleplay/android-developer/answer/12053285?hl=en), [GA4 처리 지연](https://support.google.com/analytics/answer/11198161?hl=en), [GA4 EVC](https://support.google.com/analytics/answer/12846214?hl=en), [ASA p값 원칙](https://www.amstat.org/asa/files/pdfs/p-valuestatement.pdf).

- **Lighthouse 미실측 — 필요한 것:** 설치된 Lighthouse 실행기/측정 환경. 로컬 CLI는 없으며 이번에 별도 설치하지 않았다.
- **실제 Android Chrome 데스크톱 사이트·iOS Safari 미실측 — 필요한 것:** 실기기와 원격 디버깅 연결. WebKit 브라우저 바이너리도 로컬에 없다. Chromium 폭/터치 에뮬레이션과 구분한다.
- **키보드만으로 파일 선택·네이티브 select 포함 전 과업 완주 미실측 — 필요한 것:** 네이티브 파일 대화상자/키보드 입력을 지원하는 실브라우저 환경. Tab 포커스·카드 이동·DOM 선택값 검사는 전체 키보드 완주를 대체하지 않는다.
- **모든 라우트별 번들 크기·모든 본문 페이지의 차트 유입 전수 미실측 — 필요한 것:** production 라우트별 로딩 청크 측정. 빌드 성공만으로 성능이 좋다고 판단하지 않는다.
- **Meta 현재 계정별 요건 미확인 — 필요한 것:** 로그인된 공식 도움말/실제 광고 계정 설정 확인. 오래된 공통 규칙은 제거했지만 최신 콘솔을 검증했다고 주장하지 않는다.
