# MMM 비즈니스 계절성 v2 설계·테스트 플랜

## 0. 목적

이 문서의 목적은 현재 `annual-4` 결과를 무조건 유지하는 것이 아니다.

목표는 다음 질문에 정직하게 답하는 MMM을 만드는 것이다.

> 광고·이벤트·업계 흐름·장기 추세를 제외하고도, 실제 비즈니스 수요에서 해마다 재현되는 흐름이 존재하는가?

존재한다면 다음을 지표로 제공한다.

- 계절성 존재 여부
- 계절성 신뢰도
- 수요가 높은 시기와 낮은 시기
- 최고점과 최저점의 차이
- 해마다 모양·크기·시점이 얼마나 달라졌는지
- 어떤 조건에서 결과가 불안정해지는지

계절성이 충분히 입증되지 않으면 `없음` 또는 `근거 부족`으로 표시한다. 참고 화면과 비슷한 곡선을 만드는 것보다 통계적 정직성을 우선한다.

## 2. 최종 모델 후보

현재 후보를 폐기하지 않고 새로운 후보와 공정하게 비교한다.

### M0 — 계절성 없음

- 목적: 모든 계절성 모델의 기준선
- 의미: 광고·이벤트·업계 흐름·추세만으로 RR을 설명

### M1~M4 — 현재 annual 후보

- M1: `annual-1`
- M2: `annual-2`
- M3: `annual-3`
- M4: `annual-4`

현재 결과와의 연속성을 유지하고 회귀 여부를 확인하는 기준 후보다.

### M5 — 부드러운 비즈니스 연간 모양

- 52주를 몇 개의 부드러운 구간으로 나눠 실제 RR 모양을 학습
- 고정된 사인파 조합보다 봉우리와 골을 유연하게 표현
- 시작 주와 마지막 주가 끊기지 않도록 순환형 곡선 사용
- 후보 복잡도: 6개 구간과 8개 구간을 비교

쉬운 설명:

> 정해진 물결 여러 개를 합치는 대신, 실제 연간 수요 곡선을 부드럽게 그리는 방식이다.

### M6 — 공통 계절 모양 + 연도별 크기 변화

- 모든 해가 공유하는 기본 계절 모양
- 2024년·2025년별로 계절성 크기가 조금 달라지는 항
- 연도별 차이는 0에 가깝게 눌러 과도한 변화를 방지

쉬운 설명:

> 바쁜 시기는 비슷하지만 올해가 작년보다 더 강하거나 약할 수 있게 한다.

### M7 — 공통 계절 모양 + 연도별 시점 변화

- 공통 계절 모양은 유지
- 연도별 최고점·최저점이 최대 몇 주 이동할 수 있음
- 허용 이동 범위는 ±6주
- 이동 폭이 클수록 벌점을 부여

쉬운 설명:

> 성수기가 매년 정확히 같은 주에 오지 않아도, 비슷한 흐름이면 같은 계절성으로 본다.

### M8 — 비즈니스 달력 모델

- 반복 계절 모양과 별도로 다음 항목을 명시적으로 분리
  - 명절
  - 크리스마스 전후
  - 분기 시작·종료
  - 월말·연말
  - 사용자가 매핑한 비즈니스 이벤트
- 이벤트 열이 없으면 자동 생성하지 않음

쉬운 설명:

> “매년 이맘때 수요가 오른다”와 “크리스마스라서 올랐다”를 분리한다.

### 권장 통합 후보 M9

`M5 공통 연간 모양 + M6 연도별 크기 변화 + M8 실제 이벤트`

M7 시점 변화는 데이터가 3년 이상일 때만 최종 모델 후보로 허용한다. 2년 데이터에서는 시점 이동이 실제 변화인지 우연인지 구분하기 어렵기 때문이다.

## 3. 데이터 길이에 따른 허용 범위

| 유효 이력 | 허용 결과 | 신뢰도 상한 |
|---|---|---|
| 52주 미만 | 계절성 자동 판정 금지 | 없음 |
| 52~95주 | 단순 annual 참고선만 표시, 자동 확정 금지 | 약함 |
| 96~155주 | M1~M6 비교 가능, 연도별 시점 이동은 진단 전용 | 보통 |
| 156주 이상 | M1~M9 전체 비교 가능 | 강함 가능 |

현재 103주 데이터는 결과가 아무리 좋아도 `보통`보다 높은 신뢰도를 부여하지 않는다.

## 4. 핵심 검증 1 — 실제 연도 간 반복성

### 4.1 계산 절차

1. 계절성을 넣지 않은 모델을 적합한다.
2. RR에서 다음 기여를 제거한다.
   - Trend
   - Holidays & Events
   - Industry Trend
   - Performance
   - Brand
3. 남은 값을 연도와 달력 주차로 정렬한다.
4. 2024년과 2025년을 각각 1~52주 모양으로 만든다.
5. 결측 주는 양쪽 주의 값으로 보간하되, 보간 주 수를 기록한다.
6. 5주 순환형 중앙값 또는 평균으로 급격한 잡음을 완화한다.
7. 모델이 만든 곡선이 아닌 두 해의 실제 잔여 RR 모양을 비교한다.

### 4.2 계산 지표

| 지표 | 의미 |
|---|---|
| `observedYearCorrelation` | 두 해의 실제 모양이 얼마나 비슷한지 |
| `signAgreement` | 같은 시기에 둘 다 평균보다 높거나 낮은 비율 |
| `peakShiftWeeks` | 두 해 최고점 시기의 차이 |
| `troughShiftWeeks` | 두 해 최저점 시기의 차이 |
| `amplitudeRatio` | 두 해 계절성 크기의 비율 |
| `observedCorrelationCi` | 반복성 추정의 불확실성 범위 |

### 4.3 1차 합격 기준

`보통` 계절성:

- `observedYearCorrelation >= 0.60`
- `signAgreement >= 0.65`
- `peakShiftWeeks <= 6`
- `troughShiftWeeks <= 6`
- `0.50 <= amplitudeRatio <= 2.00`
- 반복성 상관의 90% 신뢰범위 하한이 0.20 초과

`강함` 계절성:

- 이력 156주 이상
- `observedYearCorrelation >= 0.75`
- `signAgreement >= 0.75`
- 최고점·최저점 차이 각각 4주 이하
- 반복성 상관의 90% 신뢰범위 하한이 0.40 초과

실패 처리:

- 한 항목만 경계값에 못 미치면 `약함`
- 상관 0.40 미만 또는 부호 일치율 0.55 미만이면 `없음/근거 부족`
- 모델이 만든 52주 상관은 `modelPeriodicityDiagnostic`으로 이름을 바꾸고 판정에는 사용하지 않음

## 5. 핵심 검증 2 — 시간 순서 검증

### 5.1 검증을 두 종류로 분리

#### A. 분해 안정성 검증

- 미래 구간의 실제 광고 집행값 사용 가능
- 이미 알고 있는 이벤트와 실제 외부시장 값 사용 가능
- 목적: 같은 조건을 알고 있을 때 계절성 분해가 안정적인지 확인
- 화면 명칭: `조건부 분해 오차`

#### B. 실제 예측 검증

- 미래 외부시장 실측값 사용 금지
- 이벤트는 달력상 미리 아는 것만 사용
- 광고는 사용자가 입력한 계획값 또는 직전값 유지
- 목적: 실제 미래 예측 가능성 확인
- 화면 명칭: `순방향 예측 오차`

두 결과를 절대 같은 WMAPE로 합치지 않는다.

### 5.2 fold 구성

- 최소 학습 기간: 52주
- 검증 길이: 8~12주
- 검증 시작점을 약 13주 간격으로 배치
- 가능한 경우 Q1·Q2·Q3·Q4를 각각 한 번 이상 포함
- 이력 156주 이상이면 최근 2년에서 최소 6개 fold 사용

### 5.3 합격 기준

고정 `2%p` 허용값을 다음으로 교체한다.

```text
허용 악화폭 = max(0.5%p, 무계절 모델과 후보 모델 오차 차이의 표준오차)
```

후보 통과 조건:

- 평균 WMAPE가 무계절 모델 + 허용 악화폭 이하
- 전체 fold의 절반 이상에서 무계절 모델과 같거나 더 좋음
- 특정 한 fold에서 무계절 대비 3%p 이상 악화하지 않음

예측 모델로 표시할 추가 조건:

- 순방향 예측 WMAPE가 무계절 모델보다 같거나 낮음
- 위 조건을 만족하지 못하면 분해용 계절성과 예측용 계절성을 분리

## 6. 핵심 검증 3 — 추세 민감도

### 비교할 추세 방식

1. 직선 추세
2. 중간에 한 번 꺾이는 추세
3. 중간에 두 번 꺾이는 추세
4. 완만하게 움직이는 부드러운 추세

### 기록할 값

- 각 방식의 계절성 존재 여부
- 선택 후보
- 계절성 곡선 상관
- 계절성 최고점·최저점 시기
- 계절성 최고점과 최저점 차이
- Trend와 Seasonality 사이의 기여 이동량

### 합격 기준

- 4개 중 최소 3개 방식에서 계절성 존재 판정 일치
- 추세 방식 간 계절성 곡선 상관 중앙값 0.80 이상
- 계절성 크기의 변동계수 30% 이하
- 최고점·최저점 이동 각각 6주 이하

실패 시:

- `추세 선택에 민감함` 경고
- 신뢰도 한 단계 하향
- 예산·미래 예측에는 계절성 사용 금지

## 7. 핵심 검증 4 — 이벤트·외부시장·매체 민감도

### 비교 조건

| 조건 | 포함 내용 |
|---|---|
| C0 | 전체 데이터 |
| C1 | 외부시장 제외 |
| C2 | 이벤트 제외 |
| C3 | 외부시장·이벤트 모두 제외 |
| C4 | Brand/Performance 집계 매체 |
| C5 | 원래 개별 채널 |
| C6~ | 주요 이벤트 그룹을 하나씩 제외 |

### 후보 이름 외에 비교할 값

- 계절성 곡선 상관
- 계절성 크기 변화율
- 최고점·최저점 이동
- Trend·Seasonality·Brand·Performance 기여 이동
- Industry Trend 사용·제외 상태

### 합격 기준

- C0 대비 각 핵심 조건의 계절성 곡선 상관 0.85 이상
- 계절성 크기 변화 30% 이하
- 최고점·최저점 이동 각각 4주 이하
- 전체 RR 대비 각 그룹 기여 이동 15%p 이하
- 외부시장 포함·제외 시 “계절성 있음/없음” 판정 일치

이름은 같지만 위 기준이 깨지면 `controlConsensus=false`로 처리한다.

## 8. 핵심 검증 5 — 특정 주·이상치 영향

### 테스트

1. 4주 블록을 하나씩 제외하고 전체 기간을 반복 적합
2. 주요 이벤트 주를 하나씩 제외
3. RR 상·하위 1% 주를 제외
4. 광고 집행이 급변한 주를 제외

### 합격 기준

- 반복 실행의 80% 이상에서 계절성 존재 판정 유지
- 원래 곡선과의 상관 중앙값 0.85 이상
- 최고점·최저점 이동 중앙값 4주 이하
- 계절성 크기 중앙값 변화 25% 이하

실패 시:

- 결과에 영향을 준 주차를 리스트로 표시
- `몇 개의 특이 주에 민감함` 경고
- 신뢰도 한 단계 하향

## 9. 핵심 검증 6 — 계절성 불확실성

### 방법

- 4주 단위 잔차 블록을 재배치해 200개 표본 생성
- 입력 데이터 해시를 고정 seed로 사용
- `Math.random` 사용 금지
- 같은 입력이면 항상 같은 결과

### 출력

- 주별 계절성 중앙값
- 80%·90% 신뢰범위
- 최고점 주차의 범위
- 최저점 주차의 범위
- 최고점과 최저점 차이의 범위

### 합격 기준

- 합성 데이터에서 90% 범위의 실제 곡선 포함률 80~95%
- 계절성이 없는 합성 데이터의 강한 계절성 오판율 5% 이하
- 계절성이 있는 합성 데이터에서 신호 크기가 평균 RR의 4% 이상일 때 검출률 80% 이상

## 11. BIC와 복잡도 점수 개선

### 현재 문제

현재 BIC는 모든 열이 똑같이 자유롭게 움직였다고 가정한다. 실제 모델은 일부 계수를 강하게 눌러 안정화하므로 실제 복잡도와 다를 수 있다.

### 개선안

1. 실제로 움직이는 정도를 반영한 `effectiveDf` 계산
2. 표본이 작은 103주 데이터에는 AICc도 함께 계산
3. 다음 세 값을 모두 기록
   - `approxBic`
   - `aicc`
   - rolling WMAPE
4. 화면에서는 BIC 하나를 “정답 점수”처럼 표시하지 않음

### 선택 규칙

- 실제 반복성 검증 통과가 첫 번째
- 민감도 검증 통과가 두 번째
- rolling 안정성이 세 번째
- BIC/AICc는 통과 후보 사이의 복잡도 비교에만 사용

## 12. Industry Trend 검증

외부시장 열이 매핑된 경우 다음을 반드시 기록한다.

- `industryStatus`: `used`, `dropped-collinear`, `constant`, `missing`
- 사용된 외부시장 열 목록
- 제외된 열과 이유
- Industry Trend 주별 기여
- 최소 한 주에서 절대 기여가 0보다 큰지
- 평균이 0에 가까운 경우 “기준 대비 상대 변화라 평균이 상쇄됨” 설명

### 합격 기준

- 변화가 있는 외부시장 열이 정상 매핑되고 공선이 아니면 `Industry Trend` 그룹 존재
- 주별 값 중 최소 하나가 `1e-6`보다 큼
- 분해 합계가 최종 fitted RR과 일치
- 제외된 경우 화면에서 이유 표시

## 13. 참고 화면 유사성 검증

참고 화면과의 유사성은 통계 검증을 통과한 후보 사이에서만 사용한다.

### 비교 항목

- 연간 최고점 시기
- 연간 최저점 시기
- 0선을 위·아래로 통과하는 시기
- 최고점과 최저점 차이
- 곡선 상관
- 상승·하락 전환점 수

### 합격 기준

원본 숫자 데이터가 있을 때:

- 곡선 상관 0.80 이상
- 최고점·최저점 차이 각각 4주 이하
- 진폭 비율 0.50~2.00

이미지만 있을 때:

- 육안으로 표시한 6개 핵심 구간의 방향 일치 여부를 참고값으로 기록
- 픽셀 유사도를 모델 선택 기준으로 사용하지 않음
- 통계 검증보다 참고 화면 유사성을 우선하지 않음

## 15. 실제 RR CSV 테스트 절차

### R01 — 입력 고정

- 현재 `annual-4` 결과와 허용 오차 내 일치

- 2024·2025년 잔여 RR 모양 비교
- 상관·부호 일치·최고점·최저점·진폭 기록
- 이 단계 결과에 따라 현재 `annual-4` 신뢰도를 다시 결정

### R04 — 새 후보 비교

- M5~M9 실행
- 현재 M4와 동일한 검증표 생성
- R²만 좋아지고 반복성·rolling이 나빠지는 후보는 탈락

### R05 — 민감도

- 추세 4종
- 외부시장·이벤트·매체 조건
- 4주 블록 제거
- 주요 이벤트 제거

### R06 — 불확실성

- 200개 결정론적 블록 표본
- 계절성 범위·최고점·최저점 범위 생성

### R07 — 최종 판정

최종 후보는 데이터가 결정한다. `annual-4` 유지 자체를 합격 조건으로 두지 않는다.

가능한 결론:

- `annual-4 유지`
- `M5/M6/M9로 교체`
- `계절성 약함`
- `계절성 근거 부족`

### 현재 데이터의 최소 합격 조건

- 분해 합계 오차 최대 0.02 RR 미만
- 실제 연도 반복성 `보통` 기준 통과
- 추세 4종 중 3종 이상에서 계절성 존재
- 핵심 control 조건에서 곡선 상관 0.85 이상
- rolling 허용범위 통과
- 이상치 제거 반복의 80% 이상에서 존재 판정 유지
- 예산 기능은 현재 식별 문제 때문에 계속 차단

## 21. 1차 실행 상태

2026-07-24 기준으로 P0의 실제 연도 반복성 게이트를 먼저 실행했다.

- 실행 완료: 실제 연도별 잔여 RR 비교, 외부시장·이벤트·매체 집계 민감도, M0~M5 production 비교, M6/M7/M9 탐색, 4주 제거 안정성, 고주파 차등 규제 후보
- 결과: 제공 CSV의 5개 조건 모두 `weak`
- 현재 판정: `business-harmonic-shrink` 선택. annual-4의 큰 흐름은 유지하고 짧은 파동을 더 강하게 규제
- 아직 보류: 3년 이상 데이터 검증, 200회 블록 재표본, M6/M7/M9의 production 자동선택 허용
