## 기록 형식

각 행에 대해 날짜, 사용한 검색 환경, 답변 정확성(정확/조건 누락/오답), 브랜드·URL 언급, 근거 출처, 도구 진입 여부를 남긴다. 오답이나 오래된 플랫폼 규칙은 콘텐츠 이슈로 등록하고, 출처가 없는 상태에서 답변 문구만 강화하지 않는다.
