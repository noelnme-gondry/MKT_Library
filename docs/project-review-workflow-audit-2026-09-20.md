## 후속 수정 순서

1. 비교 계약을 모든 결정에 적용하고, 보관 완료 후에만 검토 완료 처리한다.
2. 초안 전환 보호와 계정 읽기/쓰기 실패 처리를 고친다.
3. 계정/로컬 메모 충돌 처리와 자동 검토 후보 선택을 정리한다.
4. 브라우저의 기준값 복원·프로젝트 생성 간헐 실패를 순서 추적해 원인을 확정한다.
