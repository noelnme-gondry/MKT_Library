# 5-2 Pro 대시보드 편집 — 구현 전 설계

상태: 2026-09-30 사용자 승인 후 구현·검증 중. 기본 탭 정돈 → 공통 편집기 → 저장/복원 순서로 진행.

## 목적

마케터가 자신의 점검 순서에 맞춰 KPI·차트를 배치하고, 동일한 지표를 서로 다른 국가·채널·기간으로 나란히 비교한다. 기본 분석은 무료로 유지하고 화면 구성 편집을 Pro의 반복 사용 가치로 만든다. `design.md`의 목적별 흰색 면, 내부 정렬, 직접 날짜 조작, 근거 보존 기준을 따른다.

## 현재 확인

- `InlineCardEditor`: KPI 드래그 순서·표시/숨김. 크기 설정을 읽는 기반은 있으나 사용자가 리사이즈하는 기능은 미구현.
- `MetricConfigPanel` + VizTab: 보조 차트 표시·순서 편집.
- `CustomChartBuilder` + `utils/metrics/chartBuilder.js`: 스코어카드·세로/가로 막대·선·파이·도넛 생성, 차원·지표·이름 선택. 기존 차트 상세 수정과 차트별 필터는 없음.
- `CustomMetricBuilder`: 사용자 지표 정의.
- `viewConfig/customCharts/customMetrics`: 기기 및 프로젝트 설정의 기반. 전체 사용자 보드를 계정 레시피로 저장하는 계약은 별도 확장 필요.
- 위 편집 진입점·store 변경에는 일관된 Pro 권한 검사가 없음. 기존 계정 레시피/프로젝트 저장 권한과 편집 권한을 혼동하지 않는다.
- 시각화 탭 외 8개 탭을 실제 캡처했다. 본문 흰색 면·설정/설명 묶음·차트 범례 정리가 아직 남아 있다. 시즈널리티는 예시가 2024년만 포함해 연도 비교 차트를 표시하지 않는다.

## 제안하는 Pro 편집 범위

| 영역 | 사용자 조작 |
| --- | --- |
| 위치·크기 | 카드/차트 드래그 정렬, 1/3·1/2·전체 폭, 차트 높이, 구역 간 이동 |
| 구성 | 블록 추가·복제·숨김·삭제, 구역 제목·순서, 기본 배치 복원 |
| 차트 데이터 | 지표·차원·집계 간격·정렬·상위 N, 계산 가능한 커스텀 지표 |
| 차트 모양 | 호환되는 차트 종류 전환, 팔레트·계열 색상·선/막대·범례 위치·직접 수치 라벨 |
| 차트별 범위 | 국가·채널·OS·소스 조건, 독립 분석·비교 날짜, 공통 범위로 복귀 |
| 저장·출력 | 이름 붙인 보드/레시피, 복제, 화면별 보기, 편집한 모양과 적용 범위를 반영한 PNG/보고서 |

표 열 편집은 사용자 요청에 따라 이번 범위에서 제외한다. 임의 이미지 업로드는 차트 표현 편집과 다른 기능이므로 이 제안에는 포함하지 않는다.

## 화면 사용 방식

상단 `대시보드 편집 · Pro` → 현재 보드에서 블록 선택 → 오른쪽 설정 패널의 `데이터 / 모양 / 배치`에서 수정 → 미리보기 → 저장. 모바일에서는 전체 높이 편집 패널과 위/아래 이동 버튼을 제공한다. 단축키·키보드 이동, 취소, 되돌리기와 기본값 복원이 필요하다.

설정 항목을 평상시 화면에 전부 늘어놓지 않는다. 차트 머리글에는 실제 적용 범위만 짧게 남긴다. 예: `한국 · Meta · 최근 28일 · 개별 기간`.

## 필터와 수치 계약

- 기본은 공통 필터를 상속한다. 차트 전용 대상 조건은 공통 범위에 추가한다(교집합).
- 다른 국가를 나란히 비교하려면 공통 국가를 전체로 둔 상태에서 차트를 복제하고 각각 국가를 지정한다. 공통 조건과 충돌하면 0으로 위장하지 않고 해당 조건의 데이터 없음을 표시한다.
- 기간은 `공통 기간 사용 / 이 차트에서 직접 지정`을 명시적으로 선택한다. 독립 기간인 차트를 공통 기간 비교처럼 보이게 하지 않는다.
- 날짜·계열·분모·단위는 실제 집계 범위를 따르며 PNG/보고서에도 같은 범위를 기록한다.
- 리텐션 곡선·퍼널·이상탐지처럼 의미가 정해진 차트는 호환되는 표현만 허용한다. 진단 엔진·계산식·판정 기준을 꾸미기 설정으로 바꾸지 않는다.
- 식별 불가·데이터 부족·추정 한계는 편집으로 숨겨 정상 결과처럼 만들 수 없다.

## Pro 경계와 저장

기본 분석·공통 필터·기본 결과 열람은 무료. 사용자 보드 생성/변경·배치/모양/차트별 조건 편집·설정 저장은 Pro로 통일하는 제안이다. 현재 제공되는 편집 기능도 이 공통 권한 정책에 연결해야 한다.

버튼 표시뿐 아니라 편집 액션·저장 API에서도 권한을 확인한다. 원본 CSV와 필터의 실제 데이터 값은 서버에 보내지 않는다. 공용 배치/표현 규칙의 계정 저장과 값이 든 기기 설정을 분리한다. 만료 시 기존 보드는 읽기 전용으로 보존하며 기본 화면으로 돌아갈 수 있게 한다. 정확한 서버 동기화 필드와 만료 후 재적용 정책은 구현 계약에 명시한다.

## 진행 순서와 검증

1. 다른 탭의 미정리 본문을 동일한 디자인 기준으로 정돈하고 분석 블록을 식별한다.
2. 시각화 탭에서 Pro 편집 모드·블록 순서/크기/복제·차트별 범위를 먼저 완성한다.
3. 차트 종류/표현, 저장·복원·출력을 연결한다.
4. 검증된 블록만 다른 탭과 도구의 사용자 보드에 연결한다. 처음부터 모든 분석을 임의 위젯으로 전환하지 않는다.

검증: 권한 만료/조작 우회, 드래그·키보드·모바일, 공통/개별 필터 충돌, 날짜 변경, 결과 숫자와 내보내기 일치, 저장 복원, 없는 컬럼/빈 데이터, KR/EN·라이트/다크. 기존 수학 엔진과 골든값은 유지한다.

## 2026-10-01 추가 구현 — 최초 제외 범위 갱신

계정 구성 보관과 수집 보고서 연결을 추가했다. `boardContract`가 허용된 배치·표현만 직렬화하므로 실제 값이 포함된 로컬 보드 전체를 계정에 복제하지 않는다. 구성 파일은 복사본 공유이며 팀 공동 편집이 아니다. 현재 탭의 실제 그림·표·범위를 로컬 수집 보고서에 담아 기존 Word/Excel/인쇄 경로를 사용한다. API fixture·서버 계약 테스트로 확인했으며 운영 DB 마이그레이션/실계정 기기 간 확인은 남아 있다.

## 최초 구현 결정과 범위 (아래 제외 사항은 위 추가 구현으로 갱신)

- 전문 분석은 기존 섹션을 하나의 블록으로 취급한다. 조건이 다른 블록만 같은 탭의 계산 컴포넌트를 독립 범위로 렌더하고, 분석 컨트롤은 공유한다. 원래 계산 엔진은 수정하지 않는다.
- 일반 차트는 개별 블록으로 추가·복제하고 차원/지표/일·주·월 집계/정렬/상위 N/색상/범례/값 표시를 편집한다. 전문 분석의 임의 차트 종류 전환과 복제는 제공하지 않는다.
- 보드는 `viewConfig.dashboard-workspace`에 저장한다. 실제 대상 값을 포함하므로 기기/로컬 프로젝트 및 저장된 분석 설정에만 포함하며 계정 레시피로 동기화하지 않는다.
- 저장 전 변경은 draft, 기존 KPI/차트 편집도 같은 draft에 반영한다. 기존 계정 레시피는 공용 분석 조건용으로 유지한다. 계정 보드 동기화와 보드 전체 Word/PDF 출력은 이번 구현 범위가 아니다. 각 그림 PNG는 편집한 형태와 개별 범위를 사용한다.

| 위치 | as-is / 영향 | to-be / 목적 | 보존 / 검증 |
|---|---|---|---|
| 스코어카드 | 회색 바탕에 KPI가 흩어짐 | 흰색 분석 면 안에서 전후 수치 비교 | 모든 KPI·일별 상세 유지 |
| 시즈널리티·LTV·코호트 | 설정과 해석의 소속 불명확 | 같은 분석의 설정/근거를 묶고 구역별 면 분리 | 불충분 상태·성숙 조건·방법론 유지 |
| 페이싱·이상탐지·퍼널·세그먼트 | 제어/차트/표 정렬 불일치 | 조건을 먼저 읽고 관련 그림·표를 이어서 읽음 | 분석식·관측치·분모 유지 |
| 모든 탭 편집 | 지표/차트 설정 분산, 공통 필터만 적용 | 평소에는 분석, Pro 편집에서 선택 구역 설정 | 실제 데이터·권한·저장복원 브라우저 검증 |
