# 영상 사용 안내 · 2026-09-14

기준: PR #874 이후 main `8a0d43db`의 실제 UI. 영상은 가상 캠페인 데이터와 로컬 계정 시연으로 제작한다. 실거래·실제 계정 메모·사용자 CSV는 사용하지 않는다.

목록과 자막은 `videoTutorials.js` 한 곳에서 파생한다. 공개 CSV 도구 목록은 routeMap과 TOOL_GROUP에서 파생해 누락을 검사한다. 공통 매핑 영상은 운영 대시보드 예시이며, 개별 도구의 입력 형식·필드 계약을 대체하지 않는다. 각 도구의 개별 통계 방법 전체를 동영상으로 설명한 것은 아니다.

영상 버튼은 가볍게 고정하고, 동의 배너·다른 모달·입력/본문 키보드 포커스와 겹치지 않도록 숨긴다. 영상은 클릭해 안내를 연 뒤에만 자원을 요청하며 자동 재생하지 않는다. 텍스트 단계·타임스탬프 탐색·키보드 닫기와 포커스 복귀를 제공한다.

전체 회귀 CI에서 320px 영문 보고서 버튼과 플로팅 안내의 겹침을 재현했다. 스크롤 중과 기존 조작 요소에 겹치는 동안 안내 버튼이 양보하도록 수정했으며, 항상 접근할 수 있도록 상단 ‘•••’ 메뉴에도 문맥별 영상 진입을 제공한다. 기존 보고서 미리보기·구매 경계 테스트로 수정 전 실패와 수정 후 통과를 확인했다.

홈 설명은 문장별 블록, 이용 조건은 의미 단위의 인라인 블록으로 바꾸고 기존 39ch·42ch 폭 제한을 제거했다. 좁은 화면에서는 내용이 잘리거나 가로로 넘치지 않고 문장 안에서 자연스럽게 줄바꿈한다.

리텐션·전환 개선은 아직 측정하지 않았다. 영상 시작/완료 이벤트에는 공개 주제 식별자·언어만 전달하고 파일명·사용자 데이터는 포함하지 않는다. 계정/결제 운영 설정은 변경하지 않는다.

검증: 로컬 `test:all` 3,742개 통과·2개 건너뜀, lint와 production build 통과. 배포 빌드의 Chromium에서 320·768·1440px, KR/EN, 밝은/어두운 테마의 재생·키보드·접근성·매핑 상태 보존·보고서 구매 경계 36건을 통과했다. 18개 영상은 각각 36초·1280×720이며, 총 72개 장면 중간 시점의 HyperFrames 레이아웃·대비 검사를 통과했다. Safari와 모바일 실기기, 실제 결제·계정 메일 수신은 이번 검증에 포함하지 않았다.
