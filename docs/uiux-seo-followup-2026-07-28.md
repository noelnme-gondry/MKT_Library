# 도구 UI/UX·SEO 후속 개선 후보

기준일: 2026-07-28
대상: `v2-migration/` 공개 분석 도구 10개(KO/EN)

## 공통 완료 기준

- 첫 결과 화면에서 **판정 → 핵심 숫자 → 다음 행동** 순서로 읽힌다.
- 방법론·주의·재현 정보는 사라지지 않되 기본 화면에서는 접혀 있다.
- 긴 문장이 핵심 숫자보다 먼저 시선을 차지하지 않는다.
- 데스크톱·모바일에서 카드 테두리, sticky 영역, 가로 스크롤이 잘리지 않는다.
- 공개 카피와 메타데이터는 KO/EN을 동시에 갱신한다.
- 분석 수학과 판정 임계값은 변경하지 않는다.

## 이번 변경에 포함

1. 공통 결과 카드의 숫자 우선 정보 계층.
2. 소재 분석의 중복 히어로 제거.
3. 대시보드 보조 필터 접기.
4. 증분 분석 방법 선택부 압축.
5. 콘텐츠 요소 분석 결론 카드 표준화.
6. 공개 도구 10개별 고유 OG 이미지와 KO/EN 메타 연결.
7. OG/메타데이터·공통 UI 회귀 테스트.

## 후속 실행 완료

문서에 남아 있던 P1·P2 후보를 다음처럼 실제 화면에 반영했다.

- 캠페인 변동 `5-21`: 전체 변화와 원인 Top 3를 상세 표보다 먼저 노출하고, 추가 변동 근거는 접었다.
- 실험 분석 `5-4`: 3단계 설명을 2개 시작 액션으로 압축하고 Control/Test 전환율·Lift·p-value를 결과 카드 첫 숫자로 올렸다.
- 예산 배분 `5-3`: 총예산·증액/감액 채널 수·잠금/제약 수를 첫 결과에 배치하고 총 합계 비교는 접었다.
- 포화도 `5-22`: 역할 설명을 한 문장으로 줄이고 분석 가능·포화·여유 수를 그대로 첫 결과에 유지했다.
- 마케팅 반응 `5-18`: 추세·잠식·기여·예측 각 단계에 핵심 숫자와 다음 단계 CTA를 추가하고 긴 추세 설명은 접었다.
- 핵심 가치 `5-20`: 전체 사용자·목표 도달·강한 후보·Top Lift를 후보명과 함께 첫 결과에 배치했다.
- 콘텐츠 요소 `9-1`: 1차 변경의 결과 카드 구조를 유지하며 회귀 설명보다 다음 실험 액션이 먼저 노출되는지 회귀 테스트 대상으로 유지했다.

## SEO 후속 개선

| 항목 | 현재 문제 | 이번 반영 | 후속 후보 |
|---|---|---|---|
| OG 이미지 | 모든 도구가 같은 홈 OG 사용 | 도구 ID·제목·짧은 설명·대표 지표가 다른 동적 OG 생성 | 실제 공유 CTR을 도구별로 비교 |
| Twitter 카드 | 도구 페이지에 명시 설정 부족 | 도구별 `summary_large_image`와 같은 고유 이미지 연결 | 공유 디버거로 캐시 갱신 확인 |
| 구조화 데이터 | 도구마다 `SoftwareApplication` 기본 정보만 존재 | SEO 카피와 이름을 맞추고 도구별 `featureList`·클라이언트 처리 특성 연결 | 승인된 데모 화면 자산 제작 후에만 `screenshot` 연결 |
| 검색 의도 | 제목·설명은 고유하나 OG와 시각적으로 불일치 | 메타·OG가 같은 도구 카피 SSOT 사용 | Search Console 쿼리로 제목 실험 |
| 크롤링 피드 | sitemap/RSS는 공개 URL 전체를 반영 | 기존 생성 테스트 유지 | 배포 후 실제 도메인의 HTTP 상태·최종 수정일 점검 |

### 운영 확인이 필요한 항목

아래 항목은 코드만으로 완료 여부를 만들면 거짓 측정이 되므로 배포 후 실제 서비스 계정·외부 캐시에서 확인한다.

- 공유 CTR: 도구별 OG가 실제 공유된 뒤 채널별 노출/클릭 데이터로 비교한다.
- 공유 캐시: X·Facebook·LinkedIn 디버거에서 KO/EN URL을 각각 다시 수집한다.
- 검색 제목 실험: Search Console의 쿼리·페이지 CTR을 최소 2주 단위로 비교한다.
- `screenshot` 구조화 데이터: 사용자 데이터가 없는 승인된 데모 화면을 고정 자산으로 만든 뒤 연결한다. 현재 OG 카드를 실제 화면 스크린샷이라고 허위 표기하지 않는다.
- 배포 HTTP: PR 배포 뒤 canonical·OG 이미지·`sitemap.xml`·`rss.xml`의 200 상태와 최종 수정일을 확인한다.
