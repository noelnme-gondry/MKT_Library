# 검색 노출 운영 로그

검색엔진 소유 확인·피드 제출·측정 일정을 코드 변경과 분리해 기록한다. 이 저장소는 공개이므로 계정 이메일, 속성 ID, 인증 토큰, 콘솔 화면, 검색어 원본과 상세 성과 수치는 남기지 않는다. 실제 수치는 운영자 전용 콘솔 또는 비공개 시트에서 관리한다.

| 채널 | 소유 확인 | 제출 자산 | 상태 | 다음 확인 |

| 네이버 서치어드바이저 | 완료 | `https://growthoptplaybook.com/sitemap.xml`, `https://growthoptplaybook.com/rss.xml` | 완료 확인. 최초 등록일은 알 수 없으며 2026-08-04 활성 상태만 확인 | 2026-08-18 |

`llms.txt`는 공개 콘텐츠 경로를 안내하는 파일이지 검색 콘솔 제출 자산이 아니다. 검색 운영·비교 대상은 Google과 네이버로 한정한다. 비교일 전에는 노출 수만 보고 신규 글을 추가하거나 제목·본문·내부 링크를 한꺼번에 바꾸지 않는다.

## 기준 측정 창

- 기준 기간: 2026-07-07~2026-08-03(직전 완료 28일)
- 비교일: 2026-08-18 KST
- 검색 지표: 클릭, 노출, CTR, 평균 게재순위, 발견·색인 URL 수
- 제품 지표: `blog_tool_cta_clicked`, `newsletter_submit_attempt`, `data_import_start`, `data_import_success`, `data_import_failed`, `analysis_started`, `analysis_blocked`, `analysis_completed`, `analysis_result_viewed`, `decision_record_added`, `decision_review_completed`
- 유입 품질: Google·네이버 검색 랜딩 → 비데모 `analysis_completed` 비율
- 활성화: 첫 `tool_view` → 첫 비데모 `analysis_completed` 전환율과 `elapsed_bucket` 소요시간 구간
- 리텐션: `decision_record_added` → 7일·28일 안의 `decision_review_completed` 비율
- 실제 이메일 구독 완료는 사이트의 제출 시도 이벤트가 아니라 Buttondown의 확인 완료 수를 SSOT로 본다.
- 주간 핵심 지표: 비데모 `analysis_completed(result_state=ready)`와 `decision_review_completed`를 분리해 함께 본다.

## 2026-09-14 후속 실행

- CAC는 customer acquisition 활동과 비용 지표를 구분하고, CPI·가입 CPA·신규 고객 CAC를 따로 설명한다. `customer acquisition` 쿼리의 실제 랜딩은 필터된 페이지 보고서 확보 전까지 미확인이다.
- 업리프트·인크리멘탈리티는 배정·관찰 창·불확실성과 분모를 보강했다. 최초 본문 보강에서는 검색 제목을 유지했으며, 같은 날 아래 후속 작업에서 검색 개념을 복원했다. 기존 제목 실험의 기준선은 재사용하지 않는다.
- EN 기회 글 3편(iOS 측정·타겟 폭 비교·첫 분석 순서)을 KO와 함께 보강한다. 순위·클릭 개선은 아직 측정하지 않았다.
- 블로그 출처·검토 링크를 접힌 영역으로 복구하고, 데모로 상세 도구를 바로 여는 경로를 제공한다. 기존 데이터 교체 확인과 분석 전 조건 확인은 유지한다.
- GEO는 `aeo-runs/README.md` 계약으로 실제 응답과 GSC Generative AI 보고서를 분리한다. 공개 HTML·robots 접근 통과는 실제 AI 인용 성과가 아니다.

### 다음 완료 28일 기준선

9월 14일 배포 시 9월 15일~10월 12일을 첫 온전한 기준선으로 수집한다. 배포가 늦어지면 배포 다음 날부터 28일로 이동한다. 결과를 보기 전에 콘텐츠를 다시 바꾸면 해당 페이지의 기준선도 다시 시작한다.

페이지·국가·기기·검색어 구성을 맞춰 클릭과 노출을 함께 비교한다. CTR만 평균내지 않고 클릭 합 ÷ 노출 합으로 계산한다. 제목 실험은 28일·100노출 이상·평균 순위 4~10 조건을 통과한 뒤 한 변수씩 진행한다. 관찰 기간을 기다리는 것은 미구현이 아니라 측정 조건이다.

### 확인한 공식 기준

- [Google AI 최적화 가이드](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide): 검색 기본 요건·유용한 근거·보이는 콘텐츠를 우선한다. 별도 AI 전용 파일을 성과 보장으로 취급하지 않는다.
- [OpenAI 크롤러](https://developers.openai.com/api/docs/bots): 검색용 OAI-SearchBot과 학습용 GPTBot을 구분한다. robots 허용만으로 실제 접근 로그를 확인했다고 쓰지 않는다.
- [에이전트가 사용할 수 있는 웹 UI](https://web.dev/articles/ai-agent-site-ux): 실제 버튼·레이블·키보드 조작과 명확한 상태를 검증한다. 여기서 AAO는 이 사용성 관점으로 다룬다.

### 2026-09-14 검색 개념 복원

- #629·#639·#811의 실제 변경 이력과 비공개 검색어 보고서를 대조했다. 한국어 용어 제목의 영문명·영어 CAC 제목의 정식 명칭·분석 순서와 ASO 영어 제목의 주제어 축소를 확인했다. 이것을 주말 노출 하락의 확정 원인으로 판정하지 않는다.
- 카니발라이제이션, CAC, 업리프트, 인크리멘탈리티, 한계 CPA의 핵심 표현을 제목에 복원한다. 분석 순서와 ASO의 제목도 KO/EN의 실제 주제에 맞춘다. 영어판이 이미 개념을 보존한 경우 제목은 유지하고 같은 검증 계약을 적용한다.
- Uplift·Incrementality의 복원된 제목을 control로 기록하고, 다음 후보도 같은 핵심 개념을 보존한다. 이번 작업은 회귀 복원이며 실험의 승리 판정이 아니다.
- 제목 길이를 검색엔진의 고정 규칙으로 취급하던 검사를 제거하고 원고의 `searchTitleTerms`에서 실제 로더·SSR title·OG·H1·본문 검증을 파생한다. 본문 제목과 SEO 제목을 혼동하지 않는다.
- ASO 요약은 전략의 범위와 비용·조회수를 고정한 산술 예시임을 KO/EN에서 명확히 한다. 이를 제목만 바꾼 실험으로 기록하지 않는다. 제목만 수정한 용어의 본문 갱신일은 부풀리지 않는다.
- 새 GEO 자료는 Google 생성형 AI 검색의 실제 노출을 포함한다. 속성 집계와 페이지 집계는 분리하고, Google AI·ChatGPT·네이버 AI 성과를 섞지 않는다. 상세 수치는 공개 저장소에 기록하지 않는다.
- 배포 다음 온전한 날부터 페이지·로케일·검색어·국가·기기를 맞춰 관측한다. Google 일별 날짜는 PT이므로 KST 머지 시각과 구분한다. 첫 7일은 기술적 노출 이상 점검, 28일은 같은 요일 구성의 성과 비교다. 전후 비교만으로 인과를 확정하지 않는다.
