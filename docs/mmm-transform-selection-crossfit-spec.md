## 1. 문제

채널 기여 모형(`mmmBayesianLikeRun`)은 채널마다 adstock·포화 모양을 데이터로 고른 뒤, 그 모양을 **처음부터 정해져 있던 것처럼** 놓고 계수 구간을 계산한다.

1. `_mmmBayesChannelParams`(`v2-migration/src/utils/mmmMath.js:3778`)가 후보 격자(`_mmmBayesTransformCandidates`, `:3709` — 기본 설정 `MMM_METH_CONFIG.adstockGrid` 9개 × 반포화점 3 × Hill 기울기 4 = 108개, 설정에 따라 identity·log1p 추가)를 전부 만들어 **통제변수 회귀 잔차와의 양(+) 상관이 가장 큰 것**을 고른다. 전체 기간 데이터를 쓴다.
2. 그 모양으로 만든 지출 신호로 결합 회귀를 하고, `_mmmBayesianLikePosterior`(`:6748`)가 계수 사후분포의 90% 구간으로 판정한다(`:6794–6820`).
   - VIF ≥ 10 → `ABSTAIN`
   - MAP이 0 경계 → `BOUNDARY/UNIDENTIFIED`
   - q05 ≈ 0이고 상대 폭 ≥ 2 → `ABSTAIN`
   - 그 밖 → `IDENTIFIED`
3. 효과가 없는 채널도 수십 개 후보 중 하나는 우연히 잔차와 맞는다. 그 모양을 고른 뒤 구간을 계산하면 구간이 0을 벗어나기 쉽다. 사후분포 메타데이터도 `conditionalOnSelectedTransforms: true`라고 스스로 밝히고 있다(`:7090` 부근).

**실측(2026-10 감사, PR #945 작업 중):**

| 데이터 | 잡음 채널의 `IDENTIFIED` 비율 |
|---|---|
| 예시 데이터 파이프라인(6시드) | 0/6 |
| 합성 독립 AR 지출(6시드 × 3채널) | 2–6/18 (11–33%) |

**실패한 시도(되돌림 완료):** 선택 점수 순열검정, 원형 이동, 위상 무작위 대리 시계열(+FWL·HAC z).
- 가짜 지출을 넣어도 성과(y) 안에는 진짜 채널 효과가 그대로 남아 있어 귀무분포 자체가 부풀었다.
- 결과적으로 실행 시간이 20–30초로 늘거나, 예시 데이터의 진짜 채널(google·brand)까지 강등됐다.
- **교훈: 진짜 효과를 데이터에서 지울 수 없으니 "가짜 데이터로 귀무분포 만들기"는 이 구조에서 안 통한다.**

## 2. 설계 개요

**원칙:** 어떤 주의 지출 신호는 **그 주가 포함되지 않은 기간에서 고른 모양**으로 만든다.

- 효과 없는 채널: 다른 기간에서 우연히 맞았던 모양은 이 기간에서는 맞지 않으므로, 검정통계량이 평균 0으로 돌아간다.
- 진짜 채널: 다른 기간에서 골라도 비슷한 모양이 나오므로 신호가 유지된다.

**바뀌는 것:** `channelIdentification[key].verdict` 하나. 강등되면 사유 코드가 붙는다.

**바뀌지 않는 것:**
- MAP 계수, 주별 분해, 채널 기여표 숫자
- 반응곡선, 예산 시나리오, 예측
- `_mmmBayesChannelParams`의 선택 결과(화면이 쓰는 모양)

| 이력 길이 n | 검사 | 통과 조건 |
|---|---|---|
| n ≥ 78주 | §3 교차 적합 z | z > 1.96(단측 2.5% — §12 ②) |
| n < 78주 | §4 다중성 보정 z | z > z₁₋₀.₀₅/M_eff |
| 교차 적합 불가(§3.5) | §4로 폴백 | 동일 |

판정 순서(위에서 먼저 걸리는 것이 이긴다):
1. VIF ≥ 10 → `ABSTAIN`(기존)
2. MAP 0 경계 → `BOUNDARY/UNIDENTIFIED`(기존)
3. q05 ≈ 0 && 상대 폭 ≥ 2 → `ABSTAIN`(기존)
4. **선택 검사 미통과 → `ABSTAIN` + `reason: "selection-not-replicated"`(신규)**
5. 그 밖 → `IDENTIFIED`

`allowSignedMedia`(오가닉 halo 등 부호 허용 모형)에서는 단측 대신 **양측**(교차 적합 |z| > 2.24, §4는 α/2)으로 검정한다. 이 경우 선택 점수도 |상관|이다(`:3793`).

## 3. 교차 적합 검사 (n ≥ 78)

### 3.1 블록

- K = min(8, ⌊n/13⌋). n ≥ 78이면 K ≥ 6이다.
- 주를 앞에서부터 연속 K블록으로 나눈다. 길이는 ⌊n/K⌋, 나머지 주는 앞 블록부터 1주씩 더한다(결정론).
- 완충 구간 b = 4주.

**78주인 이유:** 두 조건을 함께 만족하는 최소 길이다.
- 블록이 6개 이상: 블록마다 모양이 다를 수 있어, 블록이 적으면 이어 붙인 신호의 z가 블록 한두 개에 좌우된다.
- 학습 구간(n − 블록 길이 − 2b)이 52주 이상: 연 계절성 통제(푸리에)를 학습 구간 안에서 추정할 수 있어야 한다. n = 78이면 78 − 13 − 8 = 57주다.

### 3.2 블록별 모양 선택 (k = 1..K)

1. 학습 행 T_k = 전체 − 블록 k − 블록 k 앞뒤 b주.
2. T_k만으로 통제변수 회귀를 한다(`_mmmBayesControlFeatures`, `:3673` — 같은 설정 사용). 그 잔차 r_k를 얻는다.
3. 채널마다 후보 격자를 **전체 기간 지출로** 만들되(adstock은 지출 이력만 쓰므로 y 정보가 섞이지 않는다), 상관은 **T_k 행에서만** r_k와 계산한다. 선택 기준은 지금과 같은 "양(+) 상관 최대"다.
   - 구현은 `_mmmBayesChannelParams`의 상관 루프를 행 마스크를 받는 내부 함수로 빼서 공유한다. 기존 호출은 마스크 없음 = 전체 행이라 **byte-identical**이어야 한다.
4. 채널 c의 블록 k 모양 θ_{c,k}를 기록한다.

**완충 구간이 필요한 이유:** 잔차 자기상관과 adstock 이월 때문에, 블록 바로 옆 주의 y에는 블록 안 주의 정보가 섞여 있다. 4주는 기본 adstock 격자 최대값(α = 0.8)의 반감기 약 3.1주보다 길다.

### 3.3 교차 적합 신호와 결합 회귀

1. 채널 c의 교차 적합 신호 x̃_c[t] = (블록 k(t)의 모양 θ_{c,k(t)}로 전체 기간 지출을 변환한 시계열)[t]. 블록마다 다른 모양의 값을 이어 붙인다.
2. 각 블록이 고른 모양의 시계열을 **전체 기간 기준으로** 표준화한 뒤 그 블록 구간을 가져온다(§12 ①). 모양마다 단위가 달라 생기는 계단은 없애면서, 블록 사이 지출 수준 차이는 남긴다.
3. 설계행렬 = [1, 통제변수 전체(전체 기간), x̃_1 … x̃_C]. 모든 채널을 한 번에 넣는다.
4. `fitAR1`(Cochrane-Orcutt GLS)로 계수와 표준오차를 구하고 z_c = β̂_c / SE_c(§12 ③ — Newey-West에서 바꿈).

### 3.4 판정

- 단측: z_c > 1.96(α = 2.5%)이면 통과. `allowSignedMedia`면 |z_c| > 2.24.
- 통과하지 못하면 §2 순서 4의 강등.
- **기존 판정이 이미 ABSTAIN·BOUNDARY인 채널은 건드리지 않는다**(사유 코드도 기존 것 유지).

### 3.5 교차 적합 불가 → §4 폴백

다음 중 하나면 그 채널은 교차 적합 z를 만들지 않고 §4로 판정한다(`crossFit.status = "insufficient"`).
- 학습 행 T_k 안에서 지출이 0이 아닌 주가 8주 미만인 블록이 K − 2개를 넘는다(산발 집행 채널).
- 결합 회귀가 특이행렬 등으로 실패하거나 SE ≤ 0이다.

## 4. 다중성 보정 임계 (n < 78 또는 §3.5)

1. 전체 기간 데이터로 고른 기존 모양을 그대로 쓴다.
2. 채널 c의 후보 m개 신호(전체 행)의 상관행렬 R_c(m × m)를 만든다.
3. 고윳값 λ_1..λ_m(대칭 Jacobi 회전, 결정론적 순서, 수렴 1e-10 또는 최대 100 sweep)을 구한다.
4. 유효 후보 수(Li & Ji 2005): M_eff = Σ_i [ 1(|λ_i| ≥ 1) + (|λ_i| − ⌊|λ_i|⌋) ]. 하한은 1이다.
5. z 임계 = Φ⁻¹(1 − 0.05/M_eff)(부호 허용이면 1 − 0.025/M_eff).
6. 검정 z는 §3.3과 같은 결합 회귀(GLS)를 **선택된 모양의 전체 기간 신호**로 돌린 z다.

**한계(화면 사유에도 반영):** 근사이고 보수적이다. 약한 진짜 채널을 놓칠 수 있다. 선택 점수는 통제 잔차와의 상관이고 검정은 결합 회귀라, 보정이 정확히 맞지는 않는다. 합격 기준(§7)의 실측으로 확인한다.

## 5. 반환 계약 (`channelIdentification[key]`에 추가만)

```js
selectionCheck: {
  method: "block-cross-fit" | "multiplicity-adjusted",
  z,               // 검정 z (유한값 또는 null)
  threshold,       // 교차 적합 1.96(부호 허용 2.24) / Φ⁻¹(1 − 0.05/M_eff)
  passed,          // boolean
  blocks,          // K (교차 적합만)
  buffer,          // 4 (교차 적합만)
  shapeAgreement,  // 블록 중 전체 기간 선택과 같은 (family, α) 비율 — 진단용, 판정에 안 씀
  effectiveCandidates, // M_eff (다중성 보정만)
  status,          // "ok" | "insufficient" (교차 적합 불가로 폴백한 경우)
},
reason,            // 강등됐을 때만 "selection-not-replicated"
```

- 기존 필드(`mean`·`map`·`ci90`·`vif`·`relativeWidth`·`verdict`)는 의미 불변이다.
- `posteriorApproximation`에 `selectionCheck: { enabled: true, method, blocks }` 요약을 둔다(재현 정보).

## 9. 함정 (미리 적어 둔다)

1. **통제 회귀도 학습 행만으로.** 전체 기간 통제 잔차로 블록 상관을 계산하면, 통제 계수 안에 블록 k의 y가 들어가 누수된다.
2. **adstock은 전체 기간 지출로 만든다.** 학습 행만 잘라 adstock을 다시 돌리면 블록 경계에서 이월이 끊겨 모양 자체가 달라진다. 지출은 y가 아니므로 누수가 아니다.
3. **표준화(§3.3-2)를 빠뜨리면** 진짜 채널도 모양마다 다른 Hill 단위 때문에 이어 붙인 신호에 계단이 생겨 z가 떨어진다. 블록 안에서 표준화하면 반대로 블록 사이 지출 수준 차이(효과의 근거)를 지운다.
4. **결정론.** 블록 경계·나머지 분배·Jacobi 회전 순서·동점 처리(같은 점수면 격자 순서의 앞)를 고정한다. 같은 입력이면 byte-identical이어야 한다.
5. **"식별 불가 → 효과 없음"으로 쓰지 말 것**(§8.6). 사유 문구는 "재현되지 않음/우연과 구분 못 함"이지 "효과 없음"이 아니다.
6. **신호 미배선 금지**(§7 메타 3). `selectionCheck`를 계산만 하고 화면·내보내기가 안 읽으면 없는 것과 같다. 스모크로 사유 문구가 렌더되는지 단언한다.
7. **골든 tolerance를 늘리지 말 것.** A9·A10은 정확 일치다.

**바뀐 점 세 가지 — 모두 실측에서 나왔다:**

1. **표준화 기준을 블록 안 → 전체 기간으로.** 블록 안 표준화는 블록 사이 지출 수준 차이를 지워 진짜 효과의 근거를 버린다. 각 모양을 전체 기간 기준으로 표준화하면 단위는 맞고 수준 차이는 남는다.
2. **교차 적합 임계 1.645 → 1.96(단측 2.5%, = 95% 구간이 0을 벗어남).** 선택을 아예 없앤 **고정 모양**에서도 잡음 z의 표준편차가 1.19(z>1.645가 11%)였다. 즉 남은 부풀림은 선택 편향이 아니라 소표본 추론 쪽이다. 진단 표:

   | 잡음 채널 z (104주, 180개) | 평균 | 표준편차 | z>1.645 |
   |---|---|---|---|
   | 전체 기간에서 고른 모양(현재 방식) | 0.49 | 1.27 | 16% |
   | 교차 적합 | 0.11 | 1.17 | 11% |
   | 고정 모양(선택 없음) | 0.17 | 1.19 | 11% |
   | 교차 적합, 완충 0주 / 10주 | 0.14 / 0.12 | 1.22 / 1.15 | 12% / 9% |
   | 잡음 독립(AR 0)일 때 고정 모양 | 0.16 | 1.10 | 9% |

   교차 적합은 평균을 고정 모양 수준으로 되돌렸다(선택 편향 제거 확인). 완충 길이는 결과를 거의 바꾸지 않아 4주를 유지했다.
3. **Newey-West → AR(1) GLS(`fitAR1`).** 소표본 Newey-West(L=3)는 잡음 z 표준편차 1.45, GLS는 1.17이었다. GLS 뒤에 다시 Newey-West를 거는 방식(prewhitened HAC)은 1.36~1.46으로 더 나빴다(회귀변수 대비 표본이 작을 때 sandwich가 분산을 과소추정).

**화면:** 강등 채널은 기존 ABSTAIN 렌더(0–상한, 효율 "보류") + 사유 한 줄을 쓴다. 기술 설명은 "분석 상세"의 변환 표 머리 설명에 한 문장으로 붙였다. 320px에서는 표가 상자 안에서 가로로 스크롤되어 사유 줄이 오른쪽에서 잘려 보인다. 같은 칸의 기존 경고 줄과 같은 방식이다.

**남은 한계:** 교차 적합 임계는 이 합성 설계의 실측으로 정했다. 실제 데이터의 잔차 구조가 더 복잡하면 귀무 기각률이 달라질 수 있다. 약한 진짜 채널(효과 40)은 식별률이 81%에서 63%로 떨어진다. 이 검사가 치르는 비용이다.
