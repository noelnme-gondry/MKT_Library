# 무료 분석 이후 행동 흐름 점검

## 확인된 문제와 변경

- 결과를 보고서에 추가한 뒤 같은 화면에서 결론·필터가 바뀌어도 컴포넌트의 성공 상태가 남았다. 실제 보고서 초안과 현재 결과를 비교해 표시하도록 수정했다. 재진입 때도 초안의 실제 상태를 사용한다.
- 무료 미리보기가 다운로드 메뉴 안에 있어, 구매하지 않은 사용자는 현재 분석이 어떤 자료로 남는지 발견하기 어려웠다. 결과 영역에서 미리보기를 바로 제공한다. 데모는 계속 샘플로 표시한다.
- 미리보기에서 파일로 받으려면 창을 닫고 메뉴를 다시 찾아야 했다. 실제 보고서의 결론·근거·한계를 읽은 뒤 Word/Excel Pro 다운로드로 바로 이어진다. 구매 전에는 파일 생성이 시작되지 않는다.
- 결정 저장 영역에는 지금 근거를 남기고 다음 결과와 비교하는 목적을 덧붙였다. 저장 성공을 짧게 강조하고 동작 줄이기 설정을 존중한다. 자동 비교를 지원하지 않는 도구의 한계 문구는 유지한다.

## 판단과 한계

공용 결과 카드·다운로드 허브·결정 저장 경로를 대상으로 검토했다. 모든 개별 분석의 통계 엔진을 재감사한 것은 아니다. 엔진·가격·무료 범위·환불 조건은 변경하지 않았다.

구매 필요성은 현재 결과를 실제 보고서로 보여주고, 실행과 재검토의 용도를 설명해 전달한다. 유료 사용 의향이나 전환율 상승은 아직 측정하지 않았으므로 효과를 단정하지 않는다. 반복 팝업·깜박이는 구매 버튼·자동 스크롤은 추가하지 않았다.

기존 익명 이벤트 `analysis_result_viewed`, `report_preview_opened`, `decision_review_opened`, `weekly_report_block_added`, `result_downloaded`로 단계별 이탈을 확인할 수 있다. 실제 GA 수신이나 주요 이벤트 설정까지 이번 코드 검사로 확인한 것은 아니다. 결과 내용과 원본 행은 이벤트에 전달하지 않는다.

## 검증

- 현재 결과 변경·재진입 시 보고서 추가 상태 회귀 테스트.
- KR/EN 직접 미리보기 → 유료 다운로드 게이트 테스트.
- 실제 브라우저의 데모 분석 → 보고서 미리보기 → 닫기 후 포커스 복귀 → Pro 게이트, 모바일 가로 넘침과 접근성 검사.
- 전체 테스트·린트·빌드 결과는 PR에 기록한다.
