# 용어사전 CTR 점검 기준

대상: `/glossary/*` 검색 랜딩. 목적은 노출 확대가 아니라, **같은 검색 의도에서 클릭·다음 행동이 늘었는지** 판정하는 것이다.

## 페이지 역할

| 유형 | 맡는 검색 의도 | 제목·H1 원칙 | 다음 행동 |
| --- | --- | --- | --- |
| 용어사전 | `뜻`, `이란`, 짧은 정의 | H1·DefinedTerm은 정식 용어명. 검색 제목만 질문형 | 관련 실무 글 또는 도구 |
| 블로그 | `VIF 기준`, `해결`, `계산`, `테스트 방법` | 문제·방법·판단 기준을 제목에 명시 | 해당 분석 도구 |

용어사전의 `term`은 구조화 데이터와 H1에 쓰며, `seoTitle`은 검색 결과 제목에만 쓴다. `term`에 질문형 문장을 넣지 않는다.

## 28일 비교 방법

1. 배포 뒤 28일이 지난 시점에, 직전 28일과 비교한다. 같은 요일 구성을 맞추기 위해 28일 단위를 쓴다.
2. 검색 콘솔과 네이버 서치어드바이저를 **서로 섞지 않고** 각각 페이지·쿼리 단위로 내보낸다.
3. 다음 쿼리 묶음으로 나눈다.
   - 다중공선성: `다중공선성`, `다중공선성 뜻`, `vif`, `mmm 다중공선성`
   - 업리프트: `업리프트`, `업리프트 뜻`, `uplift`, `홀드아웃 테스트`
4. 각 묶음에서 노출, 클릭, CTR, 평균 순위(제공되는 경우)를 함께 본다. CTR만으로 성공·실패를 판정하지 않는다.
5. 순위가 개선·유지되는데 CTR만 낮으면 제목·설명·첫 문단을 수정한다. 순위가 낮으면 콘텐츠 깊이·내부 링크·외부 경쟁도를 먼저 점검한다.
