# 2차 감사 후속 조치

대상 기준 main 3aab6ac (#852). 감사 문서의 주장과 현재 코드/SSOT를 다시 대조했다.

## 변경

- 주문 30회/분, 웹훅 120회/분을 Railway edge의 `X-Real-IP`별로 적용. 전체 허용량은 프로세스당 각각 600/2400회. 이미 제한된 접속자의 재시도는 전역 한도를 차감하지 않는다. IP는 프로세스 임의 키로 HMAC 처리하며 원문을 보관/기록하지 않는다. 만료 버킷을 정리하며 전역 허용량으로 메모리 증가도 제한한다.
- Railway 환경 밖에서는 전달된 IP 헤더를 신뢰하지 않고 미확인 접속자 버킷으로 묶는다. Railway edge만 외부 진입점인 배포 계약이다. 다른 프록시나 직접 노출 환경에는 해당 프록시의 인증된 주소 계약을 별도로 적용해야 한다. 다중 복제본 전체 제한 및 분산 공격 대응은 edge 계층 작업으로 남는다.
- 결제 승인은 짧은 트랜잭션에서 소유권 확인과 payment key 예약을 완료한 뒤 DB 연결을 반환한다. Toss 조회/승인 동안 연결·행 잠금을 유지하지 않는다. 이후 다시 잠그고 소유권, 금액, mode, payment key, revoked 여부를 확인한다. 영속 멱등키는 변경하지 않는다. 예약된 payment key가 다른 요청으로 바뀌지 않도록 기존 검증을 유지한다.
- 승인 성공 응답은 복귀 쿠키를 만료시키고, purchase는 세션 외 localStorage에도 주문별 전송 표시를 남긴다. 브라우저 저장소 삭제·차단 및 서로 다른 기기 사이의 exactly-once 전송까지 보장하지는 않는다. GA4의 거래 ID 중복 제거도 유지한다.
- 정상 응답으로 이용권 없음이 확인된 방문자만 동일 탭 세션에서 5분간 재조회 생략. 구매 활성화/복원 시 즉시 무효화하고 유료 이용권은 계속 서버 확인. 저장소가 없거나 네트워크 실패 시 음성 캐시를 만들지 않는다. 쿠키만 다른 탭에서 바뀌고 로컬 권한이 없는 예외에서는 최대 5분 지연 가능.
- 구매 불가 안내에서 실제 무료 보고서 샘플로 연결한다. 유료 보고서를 무료 해제하지 않는 기존 정책은 유지한다. 429에는 1분 후 재시도 안내를 한·영으로 제공한다.
- 한글 폰트를 Unicode 범위로 분할해 필요한 문자만 요청한다. 원본과 라이선스는 재생성용으로 보존한다. Pretendard의 Reserved Font Name 조건을 반영해 수정 폰트 내부 이름을 변경한다. 드문 글자의 범위도 보존하며 CSS가 모두 커버한다. 생성 스크립트는 fonttools[woff] 4.60.2 사용.
- 라이트 토큰 블록을 한곳으로 모으되 최종 실효값을 유지한다.
- `docs/service-map/`에 한·영 서비스 흐름도와 기능 표를 제공한다. 외부 광고 집행과 사람의 판단을 별도 구역으로 표현한다.

## 정정한 감사 판정

- SSOT는 미구성 시 유료 다운로드를 무료로 열지 않는 정책을 이미 명시한다.
- 운영 브리프 `.md`는 결정 기록 이동 형식으로 무료 유지한다고 SSOT 및 화면에 명시돼 있다.
- AGENTS §12.28은 실제 샘플 계산과 기간 표시를 갖춘 홈 비교를 이미 허용한다.
- GA4 웹 스트림은 동일 사용자·transaction_id의 purchase를 중복 제거한다. 재전송 가능성과 매출 이중 계상 확정은 다르다.

## 외부 확인 필요

- 운영 config 조회: enabled=true, mode=test. DB 연결·실제 결제/환불/재발급까지 확인한 것은 아니다. 운영 주문을 생성하거나 실제 거래를 실행하지 않는다.
- 통신판매업 신고번호와 공개할 전체 주소는 미제공. 확인된 사용자 입력 없이 생성하지 않는다.
- 다중 복제본 전체 제한은 공유 edge 정책이 필요하다. 현재 코드는 프로세스별 제한임을 유지한다.
- 폰트 전송량은 실제 페이지의 문자에 따라 달라진다. 기본 두 묶음 약 0.80MB는 전체 방문 다운로드량이나 Lighthouse 점수가 아니다.
