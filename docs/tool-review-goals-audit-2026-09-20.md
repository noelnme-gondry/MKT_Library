# 도구별 목표·후속 검토 감사 — 2026-09-20

## 확인된 문제와 수정

- 기여·잠식·추세·예측 화면이 공통 `5-18` ID로 결정을 저장해 도구별 목표 목록을 사용하지 못했다. 실제 단계 ID로 결과 카드와 다운로드를 연결했다.
- 기여 분석 OOS 오차, 잠식 후보 수의 표시명과 목표 목록이 달라 기본 목표가 다른 지표로 선택됐다. 명시적인 목표 키를 전달한다.
- 기여 분석의 오가닉 전환수·사용자 수 목표가 없었다. 목표 목록을 보강하고 총 전환수 유지 조건을 제공한다.
- 후속 결정이 이전 목표를 고정 복사했다. 목표·성공 기준·실험 대상·비교군·기간·새 가드레일·다음 질문을 설정할 수 있다. 이전 근거와 기준값을 새 목표의 값으로 재사용하지 않는다.
- 숫자 목표 및 실험 계획을 일반 기간 집계만으로 자동 성공 판정하지 않는다. 같은 조건의 관측값과 사전 수치 기준을 대조한다.
- 새 예측 도구 ID에서도 기존 예측-실제 연결을 유지한다. 과거 공통 ID 기록은 보존하며 명시된 원본 경로가 있는 경우에만 새 후속 결정의 도구를 복원한다.

## 사용자 경로

기여 분석 → 결정 저장 → 관측·배운 점 기록 → 후속 결정 → 오가닉 사용자 수 → 채널 홀드아웃 → 대상·비교군·관측 기간 → 기준 5,000명·상대 증가 10% → 저장 → 재방문 → 실제 5,499명은 미충족, 5,500명은 충족 → 보고서 전달.

500명 증가와 상대 10% 증가는 별도 기준이다. 수치 충족은 통계적 유의성, 총 전환수 유지, 인과효과 입증을 대신하지 않는다. 실험 집행은 자동화하지 않으며 증분 분석 진입을 제공한다.

## 검증 범위

- 공개 분석 도구 20개: 공용 결과 카드에서 목표 목록 표시, 첫 결정 저장, 후속 목표 변경·저장. 등록 목록에서 대상을 파생한다.
- 실제 MarketingResponse 기여 분석 화면: 도구 ID, 기본 OOS 목표 및 오가닉 사용자 수 목표 연결.
- KR/EN, 모바일·태블릿·데스크톱 브라우저: 로그인 저장 경계, 재방문, 관측값 수정·저장, 보고서 미리보기.
- 실제 Word 문서·Excel·텍스트 보고서에 실험 조건, 수치 목표, 관측값, 인과효과 한계 보존.
- CSV 왕복 보존, 계정 메모 제외, 일반 집계 자동 판정 차단, 기존 예측 기록 호환.
- 로컬 전체: 4,215개 통과, DB 환경 필요 2개 제외. lint 오류·경고 없음. production build 통과.

각 도구의 모든 입력 조합이나 실제 광고 플랫폼 실험 집행을 검증한 것은 아니다. 수치 목표의 관측값은 사용자가 동일 범위의 자료에서 확인해 입력한다. 원본 CSV·실험 세부정보를 서버나 분석 이벤트에 자동 전송하지 않는다.

## 후속 정정: 목표 임계값이 효과 판정처럼 보이는 문제

이 문서의 5,499명/5,500명 예시는 운영 목표 대조에만 해당한다. 이를 카니발 유무나 실험 성패 기준으로 읽게 하는 리뷰 구성을 수정했다.

- 실제 관측 변화와 목표 진행률을 연속량으로 보존한다. 5,300명은 +300명(+6%), 목표 진행률 60%다. 목표 미달을 효과 없음으로 바꾸지 않는다.
- 같은 프로젝트의 후속 분석 근거를 선택해 연결하고 원본 추정치·신뢰구간·설계 한계를 먼저 읽는다. 분석 근거 사본을 보관해 원본 기록이 빠져도 보고서에서 유지한다.
- 연결은 실험 적합성 검증을 대신하지 않는다. 광고 순증분과 오가닉 회복의 추정 대상을 혼동하지 않고, 0 포함 구간도 효과 없음으로 단정하지 않는다.
- 주요 수정: `DecisionPlanReview.jsx`, `decisionPlan.js`, `decisionReview.js`, `analysis-export/reviewBrief.js`.
- 검증: 로컬 전체 4,217개 통과·DB 2개 제외, 관련 브라우저 12개 통과, lint·build 통과. CSV·실제 Word·Excel 및 재방문 시 불확실성 보존을 확인했다.
