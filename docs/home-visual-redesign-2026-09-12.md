# 홈 시각 구성 재정리

기준 커밋: `6435badb`. 범위: 홈 히어로, 샘플 미리보기, 모바일 보조 진입. 가격·수학·권한·CSV 처리 계약은 변경하지 않는다.

## 참조한 실제 화면

2026-09-12 공개 홈페이지를 브라우저로 열고 초기 애니메이션 이후 화면을 확인했다. 고객사 로고·수치·이미지·카피는 가져오지 않았다.

- [Mixpanel](https://mixpanel.com/home/): 짧은 메시지 아래 크게 펼친 제품 미리보기와 주요 행동 두 개. 우리에게 적용할 부분은 제품을 직접 보여주는 위계다.
- [Funnel](https://funnel.io/): 왼쪽 메시지와 오른쪽 데이터 흐름 그래픽. 기능 목록보다 제품의 역할을 먼저 보여준다. 쿠키 안내가 일부 영역을 가린 상태에서도 히어로 구성을 확인했다.
- [Airbridge](https://www.airbridge.io/en): 넓은 여백, 큰 타이포, 대비가 분명한 주요 행동. 우리 제품에서 지원하지 않는 연동·고객사 증명을 모방하지 않는다.

## 적용 원칙

- 기존 Pretendard 계열과 파랑 `#315be8`, 네이비 `#192231`, 화이트 `#ffffff`, 회청색 `#f1f4f8`, 본문색 `#202938`를 유지한다. 본문·차트 배경은 기존 라이트/다크 토큰에 따른다.
- 왼쪽은 메시지 → 설명 → 샘플/CSV 행동 → 질문 링크. 오른쪽은 도치 브랜드 헤더 → 실제 샘플 수치 → 비교 차트 → 다음 확인 사항이다.
- 직전 변경에서 빠진 도치 이미지를 복원하되 작은 브랜드 요소로 제한한다. 카드·버튼을 반복하는 장식 대신 한 개의 제품 미리보기에 시각적 무게를 둔다.
- 모바일 전용 보조 메뉴를 히어로 밖으로 옮겨 주요 행동을 중복하지 않는다. 계산기·진단·템플릿·PC 링크 복사 기능은 유지한다.
- 표본 선정·기간 설명은 접근 가능한 details/summary에 둔다. 수치·그래프는 내장 데모의 실제 계산값을 그대로 사용한다.
- 기존 공용 셸과 다른 페이지의 디자인은 변경하지 않는다. KR/EN 동일하게 적용한다.
