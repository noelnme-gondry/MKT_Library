## 인크리멘탈 뜻과 인크리멘탈리티의 차이

인크리멘탈(incremental)은 일반적으로 '점진적으로 증가하는', '증분의'라는 뜻입니다. 광고에서 incremental conversions(증분 전환)는 광고가 없었다면 생기지 않았을 추가 전환을 가리킵니다. 전월보다 전환이 늘었다는 사실만으로 광고의 증분 효과가 확인되는 것은 아닙니다.

인크리멘탈리티(Incrementality, 증분성)는 '광고가 없었을 때와 비교해 무엇이 추가됐는가'를 묻는 개념입니다. 전환수가 100건이라고 모두 광고 덕은 아닙니다. 광고가 없었어도 왔을 사람의 몫을 제외한 추가 성과를 추정합니다.

```
증분 전환 = 광고가 있을 때 실제 전환 − 광고가 없었을 때 예상 전환
```

같은 대상·기간에서 광고가 있을 때 전환이 100건, 광고가 없었을 때 예상 전환이 80건이면 증분 전환 추정치는 20건입니다. 이것은 가상 계산 예제이며, 80건이라는 기준선은 대조군이나 적절한 모형으로 추정해야 합니다.

같은 사람에게 광고를 보인 경우와 보이지 않은 경우를 동시에 관측할 수는 없습니다. 그래서 증분 측정은 "광고가 없었을 때"의 기준선을 세우는 일이고, 홀드아웃·지역 분할·전후 비교는 그 기준선을 세우는 서로 다른 방법입니다.

| 개념 | 답하는 질문 | 대표 출력 |
| --- | --- | --- |
| 어트리뷰션 | 이미 생긴 전환의 공은 누구에게 줄까? | 매체별 기여 전환 |
| 업리프트 | 노출군과 대조군의 성과 차이는 얼마인가? | 전환율 차이(%p·%) |
| 인크리멘탈리티 | 광고가 없었으면 사라질 성과는 얼마인가? | 증분 전환·iCPA·iROAS |

## 어떻게 재나

가장 신뢰도 높은 방법은 [홀드아웃 테스트](/glossary/holdout-test)예요. 무작위로 나눈 두 그룹 중 한쪽에는 광고를 노출하고 다른 쪽(홀드아웃)엔 노출하지 않은 뒤, 두 그룹의 전환율 차이(=[업리프트](/glossary/uplift))를 봐요. 무작위 실험이 어렵다면 지역 대조군, 신규 켜기, 종료 후 이중차분 순으로 검토하되 설계가 약해질수록 인과 표현도 낮춰야 합니다.

## 왜 CPA·ROAS만 보면 안 되나

CPA·ROAS는 귀속 규칙에 따른 성과와 비용의 관계를 봐요. 광고 때문에 생긴 전환인지까지는 구분하지 못합니다. 증분 점추정치가 0에 가까워도 신뢰구간과 설계 품질을 확인하기 전에는 효과가 없다고 결론 내리지 마세요.

## CPA와 iCPA를 같은 분모로 계산하지 마세요

가상의 실험에서 비용이 100만 원, 귀속 전환이 100건이면 CPA는 1만 원입니다. 같은 범위의 증분 전환 추정치가 20건이면 iCPA는 5만 원입니다. 이는 계산 예제이며 특정 캠페인의 실제 증분 비율이 아닙니다.

| 확인할 것 | 판단에 필요한 이유 |
| --- | --- |
| 비용·전환·실험 대상의 범위 일치 | 계정 전체 비용을 일부 실험의 증분으로 나누지 않기 |
| 실험군·대조군 규모와 관찰 창 | 규모 차이를 보정하고 전환 지연을 맞추기 |
| 증분 추정 구간과 설계 조건 | 증분이 0 이하이거나 방향이 불명확하면 단일 iCPA를 예산 근거로 쓰지 않기 |

[증분 분석 도구](/tools/incrementality)에서는 데이터 형태와 설계를 확인한 뒤 결과와 보류 사유를 함께 보세요. 더 많은 전환 행이 대조군의 부재를 대신하지는 않습니다.

## 더 깊게 보려면

증분을 실제로 측정하는 3가지 방법(통제군·신규켜기·종료)은 [증분성 측정 글](/blog/incrementality-measurement)에서 다룹니다. 브랜드 캠페인처럼 무작위 분할이 어렵고 시계열만 있는 경우는 [브랜드 캠페인 증분 분석](/tools/brand-campaign-incrementality)에서 개입 시점 전후를 사전 추세와 함께 봅니다.
